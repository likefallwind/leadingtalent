# AI 领军人才画像重新校准 V1.1

> 本版是对 V1.0 的怀疑性重做。核心修正：`中国本土产业生态型` 不是合格的人才类型；`创业领军`、`工业领军`、`学术认证`、`中国本土` 也不是最终分析类型，只能作为采样标签或情境变量。最终分类必须来自贡献机制，而不是地域、身份或媒体标签。

## 0. 对上一版的校准结论

上一版最严重的问题是把不同层级的概念混在一起：

| 原标签 | 问题 | V1.1 处理 |
|---|---|---|
| 中国本土产业生态型 | 地域 + 产业环境 + 放大机制混合，不能作为人才类型 | 删除；中国只作为制度、市场、语言、供应链、开源生态等情境变量记录 |
| 创业领军 | 身份/组织位置，不等于贡献机制 | 降级为采样标签；需进一步拆成产品平台、组织资本、基础设施、应用落地等机制 |
| 工业领军 | 任职场景，不等于路径 | 降级为采样标签；需看其是系统基础设施、产品平台、工业研究还是组织管理 |
| 学术认证 | 外部荣誉或学术身份，不等于机制 | 降级为采样标签；需看其是方法范式、数据基准、理论框架、人才网络还是生态扩散 |
| 产业生态 | 过宽，几乎能装下所有公司型人物 | 拆成产品平台、基础设施、组织资本、场景落地、开发者生态 |

因此，V1.1 不再说“AI 领军人才有 6/7 类固定类型”，而是改为：

```text
AI 领军人物 = 一组贡献机制的组合。
每个人可以有主机制和副机制。
地域、机构、时代和市场只解释机制如何发生，不直接作为类型。
```

## 1. 重新校准后的研究方法

### 1.1 先分清三层变量

| 层级 | 例子 | 能否作为类型 |
|---|---|---|
| 贡献机制 | 方法范式、系统基础设施、数据基准、产品平台、组织资本、生态教育、治理议程、场景转化 | 可以 |
| 情境变量 | 中国、美国、大学、公司、开源社区、云平台、政策环境、供应链、资本市场 | 不可以，只能解释 |
| 证据载体 | 论文、代码、数据集、模型、产品、课程、公司、政策证词、奖项 | 不可以，只能作为证据 |

上一版错误就在于把“中国本土”这个情境变量和“产业生态”这个宽泛结果当成类型。

### 1.2 新的编码问题

每个人只问四个问题：

1. 他/她识别或定义了什么 AI 瓶颈？
2. 他/她沉淀了什么可复用资产？
3. 这个资产通过什么机制被放大？
4. 这套机制是否能被其他案例重复观察？

如果一个标签不能回答这四个问题，它就不能进入类型体系。

## 2. V1.1 贡献机制体系

| 机制 | 定义 | 典型证据 | 代表样本 |
|---|---|---|---|
| M1 方法范式 / 理论框架 | 提出改变研究方式的算法、理论、模型或问题框架 | 代表作、后续引用、方法被复用、教材化 | Hinton、LeCun、Bengio、Sutton、Goodfellow、Kaiming He、Judea Pearl |
| M2 数据 / 评测 / 基准 | 通过数据集、benchmark、评测方式或任务定义改变领域工作流 | 数据集、榜单、评测协议、任务范式、后续采用 | Fei-Fei Li、ImageNet；部分安全评测人物 |
| M3 系统基础设施 / 工具链 | 建设让他人更快训练、部署、复现或扩展 AI 的系统 | 框架、平台、训练系统、芯片、工具链、开源仓库 | Jeff Dean、Dahua Lin、Haifeng Wang、Jingren Zhou、Tianshi Chen |
| M4 产品平台 / 用户采用 | 把 AI 能力转化成真实用户、开发者或客户持续使用的平台 | 产品、API、用户规模、客户案例、开发者生态 | Sam Altman、Wang Xiaochuan、Yang Zhilin、Aidan Gomez、Zhang Yiming |
| M5 组织资本 / 人才密度 | 在不确定窗口中聚集人才、资本、算力、战略和组织节奏 | 核心团队、融资、组织扩张、关键转向、治理结构 | Demis Hassabis、Sam Altman、Dario Amodei、Kai-Fu Lee |
| M6 生态教育 / 知识扩散 | 通过课程、博客、教材、开源社区、研究机构扩散知识和实践 | 课程、文档、博客、教材、社区维护、学生网络 | Andrew Ng、Karpathy、Olah、Zhi-Hua Zhou、Maosong Sun |
| M7 安全治理 / 公共议程 | 把技术风险、评估和治理问题转化为研究、政策或组织行动 | 技术报告、政策证词、评估框架、治理机构、公共议程 | Stuart Russell、Nick Bostrom、Paul Christiano、Dario Amodei |
| M8 场景转化 / 跨域重组 | 把 AI 机制迁移到科学、机器人、制造、语音、搜索、芯片等具体领域 | 垂直产品、科学论文、工业部署、行业平台、硬件系统 | Hassabis、Linfeng Zhang、Weinan E、Kai Yu、Xingxing Wang、Jiaya Jia |

注意：M8 不是“行业人物”筐。只有当人物真正完成“AI 技术机制 + 场景瓶颈 + 可复用资产”的重组时，才进入这一机制。

这张表暴露出两个偏差：

1. **样本偏现代产业化。** M3、M4、M5、M8 合计较多，容易放大组织、资本、产品、工程和场景转化叙事。
2. **数据/评测型样本不足。** 除 Fei-Fei Li / ImageNet 外，数据、benchmark、evaluation 作为独立领军路径在样本中明显偏少。

## 4. 重新校准后的最终画像

经过怀疑性校准后，AI 领军人才画像应写成：

```text
AI 领军人才不是某种身份、地域或性格类型，
而是在关键技术或应用瓶颈处，
把判断沉淀成可复用资产，
并让资产经由共同体、系统、产品、组织、资本或治理机制持续放大的人。
```

共通底座仍保留，但要更克制：

| 共通底座 | 是否保留 | 校准说明 |
|---|---|---|
| 问题形式化与取舍 | 保留 | 所有机制都需要，但表现形式不同 |
| 机制理解 / 方法判断 | 保留 | 对 M1 最强；M4/M5 中不能从 CEO 角色直接推断 |
| 证据严谨 / 评估品味 | 保留 | 样本中证据不足，尤其创业人物公开材料较少 |
| 系统实现 / 资产沉淀 | 保留 | 需要从“会写代码”扩展为“能沉淀可复用资产” |
| 长期推进 / 自我更新 | 保留 | 需要时间线证据，不能用成就回填 |
| 表达协作 / 扩散牵引 | 保留 | 对 M6、M7、M5 权重高，对纯方法型不是同等要求 |

## 5. 重新校准后的关键发现

1. **类型必须按机制分，不按人群分。** “中国本土”“创业者”“工业界”都是样本属性，不是领军机制。

2. **同一个人常常是机制组合。** Altman 是 M4 + M5，Hassabis 是 M5 + M8，Fei-Fei Li 是 M2 + M6 + M7，Jeff Dean 是 M3 + M5。单一标签会扭曲画像。

3. **组织型人物不能替代技术型证据。** CEO 或创始人可以校准组织资本、产品平台、外部信任，但不能自动校准机制理解、实验品味或系统实现。

4. **现代中国样本更应作为情境压力测试。** 它们提示中国语境下数据、政策、供应链、开源、云平台、产业客户会影响放大机制，但这不是一个单独“人才类型”。

5. **主样本仍缺少负样本和对照组。** 目前只能说“这些机制在领军人物中稳定出现”，不能严格证明“没有这些机制就不能领军”。

6. **历史校准让画像更稳。** McCarthy、Minsky、Newell、Simon、Feigenbaum、Reddy、Pearl、Hopfield 等历史人物也符合“问题形式化 -> 可复用资产 -> 共同体放大”的机制链，说明这个结论不是大模型时代叙事。

## 6. 对阶段二学生画像的修正

学生画像不再输出“接近中国本土产业生态型”这类标签。建议输出：

```text
该学生目前有哪些机制早期信号？
- M1 方法范式：是否能提出有机制解释的问题和方法改造？
- M2 数据评测：是否能定义任务、数据和可信评估？
- M3 系统基础设施：是否能沉淀可复用工具链？
- M4 产品平台：是否能把 demo 变成真实用户工作流？
- M5 组织资本：是否能牵引小团队和资源完成复杂任务？
- M6 生态教育：是否能让他人理解、复用和持续参与？
- M7 安全治理：是否能把技术风险转化为评估或行动？
- M8 场景转化：是否能把 AI 技术与真实领域瓶颈重组？
```

输出格式应是“机制信号 + 证据充分度 + 下一步补证据”，而不是人物类型标签。

## 7. V1.1 边界

V1.1 比 V1.0 更可靠，但仍有边界：

1. 60 人样本仍是正样本集合，不是严格因果识别。
2. 历史校准只补了 9 位高共识人物，不是 AI 史完整谱系。
3. 很多创业和工业人物的公开材料仍偏公司叙事，需要事件卡和第三方证据继续压实。
4. 统计人数是主机制人工重编码，适合校准框架，不适合当作精确分布结论。

## 8. 一句话校准版结论

AI 领军人才不是“某类人”，而是能把 AI 关键瓶颈转化为可复用资产，并让资产通过明确机制放大的人。地域、身份、公司、荣誉都只能作为解释变量或证据载体，不能直接成为画像类型。
