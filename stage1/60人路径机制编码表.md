# 60 人路径机制编码表 V1.0

本表把 `scrape/data/names_seed.csv` 与 `scrape/data/manual_sources.csv` 中的 60 人样本转化为“路径-机制”编码。它不是人物传记，也不是能力打分表；用途是支撑最终画像报告中的跨案例归纳。

## 编码规则

| 字段 | 含义 |
|---|---|
| 证据等级 | 来自 `manual_sources.csv` 的补强后质量，A 用于主校准，B 用于主分析和路径覆盖 |
| 主路径 | 此人在样本中最主要的 AI 影响形成路径 |
| 机制链摘要 | 按“问题偏好/关键行为 -> 可累积资产 -> 放大机制 -> AI 影响”压缩描述 |
| 画像锚点 | 该案例对领军人才画像贡献最大的可观察能力 |
| 约束 | 该案例不能被过度泛化的地方 |
