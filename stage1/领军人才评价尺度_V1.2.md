# 领军人才评价尺度 V1.2

本尺度是阶段一 V1.2 产物，来源于 60 人名单的公开材料抓取、证据质量审计、人工可信源补强和原子能力修订。它用于阶段二映射学生数据时试用，不是最终定稿。

## 使用原则

1. 先看证据，再给档位。没有证据不能推断为能力低。
2. 能力水平和证据充分度分开记录。
3. 不计算总分，只做画像、路径判断和培养建议。
4. A/B 级证据可以支撑初步判断；C 级只做背景；D 级不建议评分。
5. 4 档不是要求学生达到名人成就，而是指其同阶段行为证据接近代表人物早期特征。

## 总体档位

| 分值 | 含义 |
|---:|---|
| 0 | 无证据，不能判断 |
| 1 | 有零散证据，但表现弱或不稳定 |
| 2 | 有稳定证据，达到合格研究者/工程者水平 |
| 3 | 有多源证据，明显高于同阶段同伴 |
| 4 | 有强证据，接近领域代表人物早期特征 |

## 证据质量

| 等级 | 含义 |
|---|---|
| A | 多源证据一致，包括作品、行为记录、他人评价或外部采用 |
| B | 有明确作品或行为证据，但来源较单一 |
| C | 主要来自自述、简历、新闻稿或间接材料 |
| D | 证据不足，或存在明显错配风险，不建议评分 |

## A. 智识判断

### A1. 问题嗅觉

识别什么问题真正重要、什么问题只是热闹的判断力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无材料显示其如何选择问题 |
| 1 | 跟随热点做题，但看不出独立取舍 |
| 2 | 能解释选题价值，问题有明确研究或应用意义 |
| 3 | 多次选择高价值问题，并能避开低价值热闹方向 |
| 4 | 在领域共识形成前识别关键问题，并持续推动成主流议题 |

典型证据：选题陈述、论文 introduction、访谈、项目取舍记录、研究路线变化。

### A2. 理论/机制深度

理解底层机制，而不是只会调用工具或复述概念。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无理论或机制理解证据 |
| 1 | 能复述概念，但缺少推导、机制解释或边界分析 |
| 2 | 能解释方法原理，并在项目中正确使用 |
| 3 | 能提出机制性解释、改进方法或连接多个理论框架 |
| 4 | 形成被领域采用的基础概念、方法或理论框架 |

典型证据：论文方法部分、技术报告、推导笔记、课程讲解、失败原因分析。

### A3. 系统性思维

拆解复杂问题、组织系统和长期任务的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无复杂任务拆解证据 |
| 1 | 只能完成局部任务，缺少整体结构 |
| 2 | 能把项目拆成模块，并说明模块关系 |
| 3 | 能设计可扩展架构或长期研究路线 |
| 4 | 能组织跨模块、跨团队、跨阶段的大系统并长期演进 |

典型证据：系统设计文档、项目路线图、代码架构、研究计划、跨团队协作方案。

### A4. 反共识判断

在主流方向之外形成独立判断，并能给出理由。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无独立判断证据 |
| 1 | 偶尔表达不同意见，但理由弱或不持续 |
| 2 | 能对主流方法提出有根据的批评 |
| 3 | 能在非主流方向持续投入，并形成阶段性成果 |
| 4 | 长期坚持后来被证明重要的非共识路线 |

典型证据：早期论文、方向选择、访谈、研究组路线、对热门方向的技术批评。

### A5. 实验与评估品味

知道什么实验可信、什么指标有意义、什么结果只是偶然。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无实验设计或评估证据 |
| 1 | 会跑 benchmark，但缺少控制变量和解释 |
| 2 | 能做基本 ablation、误差分析和复现实验 |
| 3 | 能设计揭示机制或边界的实验，避免误导性结论 |
| 4 | 其评估方法、benchmark 或实验范式被领域广泛采用 |

典型证据：ablation、benchmark 设计、错误分析、复现报告、实验边界说明。

## B. 工程与产品

### B1. 代码/系统实现力

把 idea 做成 working system 的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无实现作品 |
| 1 | 能完成小规模代码，但质量和复用性弱 |
| 2 | 能完成可运行项目，有基本工程结构 |
| 3 | 能交付复杂系统，代码质量、性能和可维护性较好 |
| 4 | 构建的平台、框架或系统被广泛使用或支撑重要成果 |

典型证据：GitHub、项目仓库、系统 demo、部署记录、代码 review、外部采用。

### B2. 速度/迭代节奏

快速试错、验证和调整的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无时间序列证据 |
| 1 | 有零散产出，但节奏不稳定 |
| 2 | 能按周期推进任务，持续迭代 |
| 3 | 面对新问题能快速产出 prototype 并持续改进 |
| 4 | 在领域窗口期中快速形成高质量成果或组织级响应 |

典型证据：commit 时间线、版本迭代、项目里程碑、模型/产品发布节奏、短周期实验记录。

### B3. 产品化/场景定义

把技术能力转成真实任务、产品形态或用户价值的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无应用场景或用户定义证据 |
| 1 | 能描述应用方向，但场景模糊 |
| 2 | 能把技术映射到明确任务、用户或工作流 |
| 3 | 能根据真实反馈调整产品/系统形态 |
| 4 | 定义的新产品、平台或应用范式产生行业级影响 |

典型证据：产品文档、用户反馈、应用案例、商业化路径、开源采用、产品迭代说明。

### B4. 数据/算力/基础设施杠杆

判断并利用数据、算力、平台和基础设施放大技术能力的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无数据、算力或基础设施判断证据 |
| 1 | 能使用现成资源，但缺少主动设计 |
| 2 | 能为项目选择合适数据、算力和工程工具 |
| 3 | 能设计数据/算力/平台策略，显著提升项目效率或能力上限 |
| 4 | 构建或主导的基础设施成为团队、机构或行业竞争优势 |

典型证据：数据策略、训练基础设施、平台架构、算力规划、工具链建设、规模化工程决策。

## C. 内驱成长

### C1. 长期专注与韧性

持续投入难题并经受失败的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无长期投入证据 |
| 1 | 对难题有兴趣，但持续性不足 |
| 2 | 能在一个方向持续投入一个阶段，并完成成果 |
| 3 | 面对失败、冷门或挫折仍能持续推进 |
| 4 | 长期坚持困难方向，最终形成领域级突破或组织积累 |

典型证据：多年研究线、失败后复盘、方向连续性、项目长期维护、冷门期持续投入。

### C2. 跨范式迁移与自我更新

在 AI 快速变化中跨模型、任务、工具链或组织阶段迁移，并产出高质量成果的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无学习迁移证据 |
| 1 | 能学习新工具，但主要停留在使用层 |
| 2 | 能较快进入新模型、新任务或新工具链 |
| 3 | 能跨方向迁移并产出有质量的成果 |
| 4 | 多次跨范式迁移，并在新方向中形成领先判断或成果 |

典型证据：跨方向项目、技术迁移、工具链更新、从旧范式进入新范式后的成果。

## D. 外向影响

### D1. 技术表达与解释力

写、讲、解释复杂技术问题并让他人理解的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无表达材料 |
| 1 | 能说明自己做了什么，但结构不清 |
| 2 | 能清晰解释技术问题和项目价值 |
| 3 | 能把复杂概念讲清楚，并影响他人学习或采用 |
| 4 | 其课程、博客、论文、演讲成为领域重要解释框架 |

典型证据：论文写作、报告、课程、博客、公开演讲、技术文档、教学反馈。

### D2. 社区/生态建设

进入 AI 社区、开源生态、课程生态或产业生态并产生贡献的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无外部社区或生态参与证据 |
| 1 | 参与会议、社群或开源，但贡献较浅 |
| 2 | 有稳定外部贡献，如 PR、issue、教程、workshop |
| 3 | 能组织社区活动、维护项目或影响实践标准 |
| 4 | 构建或显著推动一个领域生态、课程生态、开源生态或产业生态 |

典型证据：开源贡献、社区维护、课程平台、workshop、标准制定、外部采用。

### D3. 外部叙事与信任建立

让投资人、客户、开发者、研究者、合作方或公众相信一个方向并持续投入的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无外部叙事或信任建立证据 |
| 1 | 能介绍愿景，但停留在口号或宣传 |
| 2 | 能把方向、能力和行动讲清楚，并获得初步外部支持 |
| 3 | 能持续获得关键外部利益相关者信任，推动合作、采用或投入 |
| 4 | 其叙事和信任网络显著改变组织、社区或行业资源流向 |

典型证据：融资材料、客户采用、开发者生态、发布会、访谈、合作协议、外部评价。

## E. 组织领导

### E1. 愿景与议程设定

提出一个值得他人长期投入的方向、目标或组织叙事。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无愿景或方向表达证据 |
| 1 | 有目标表述，但宽泛、不可执行 |
| 2 | 能提出清楚方向，并和项目行动一致 |
| 3 | 能让团队或合作者围绕该方向持续投入 |
| 4 | 设定的议程影响机构、行业、社区或研究方向 |

典型证据：研究纲领、创业使命、组织战略、公开演讲、长期路线图、团队行动一致性。

### E2. 人才吸引与团队构建

吸引强人、组织互补团队、形成高密度协作的能力。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无团队组织证据 |
| 1 | 参与团队，但看不出组织贡献 |
| 2 | 能组织小团队完成任务，分工基本合理 |
| 3 | 能吸引强合作者，形成互补团队并持续产出 |
| 4 | 构建高影响力团队、实验室、公司或生态组织 |

典型证据：团队成员背景、共同作者网络、核心人才加入、带学生记录、组织扩张、团队成果。

### E3. 资源整合与关键决策

在不确定条件下整合资金、算力、数据、合作方并做关键取舍。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无资源整合或决策证据 |
| 1 | 能利用已有资源完成任务，但缺少主动整合 |
| 2 | 能为项目争取必要资源并做基本取舍 |
| 3 | 能在资源受限或不确定时做关键决策，推动项目突破 |
| 4 | 通过资源组织和关键取舍改变团队、机构或行业竞争位置 |

典型证据：融资、算力规划、数据获取、合作谈判、路线转向、预算和人力配置、关键时点决策。

## 过程证据项：复现与调试力

复现与调试力不进入 V1.2 名人公开画像主尺度，但阶段二必须单独观察。理由是：它对博士培养高度重要，却常常不会出现在名人公开材料里。

| 分值 | 行为锚点 |
|---:|---|
| 0 | 无复现或调试证据 |
| 1 | 能照着说明跑通，但无法解释失败原因 |
| 2 | 能复现主要结果，并记录关键配置和误差来源 |
| 3 | 能定位复杂 bug，修正实现问题，并解释差异 |
| 4 | 复现、调试或工程修正被他人采用，提升领域可复用性 |

典型证据：复现报告、issue、PR、debug 记录、配置说明、复现实验对照。
