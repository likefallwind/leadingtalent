# 阶段一研究报告：60 人证据审计与原子能力 V1.1

## 1. 为什么重做

前一版阶段一产物有两个硬伤：

1. 只基于 24 位代表人物做归纳，没有覆盖 `scrape/data/names_seed.csv` 中的完整名单。
2. 没有先审计自动抓取来源，容易把同名错配、百科搜索错配和低质量材料混进画像抽取。

因此，本版不再把“16 个原子能力”当作结论，而是把它当作 V0 假设，用 60 人公开材料抓取结果做一次证据质量审计，再决定哪些能力保留、修改、新增或降级。

## 2. 本轮实际做了什么

本轮对名单中的 60 人全部生成了 `scrape/data/traces/{id}/profile.md`，并建立了证据审计矩阵。

抓取配置：

| 配置 | 说明 |
|---|---|
| `scrape/config_stage1_fast.yaml` | 跳过 arXiv，抓 Semantic Scholar / Wikipedia / GitHub / 个人主页 |
| `scrape/config_stage1_minimal.yaml` | 跳过 arXiv 和 GitHub，用于避开 GitHub rate limit 后补抓 |

关键事实：

| 项 | 结果 |
|---|---:|
| 名单人数 | 60 |
| 已生成 profile | 60 |
| A 级证据 | 9 |
| B 级证据 | 20 |
| C 级证据 | 26 |
| D 级证据 | 5 |
| 存在疑似自动源错配风险 | 42 |

这说明：代码可以帮助收集材料，但当前自动抓取结果不能直接作为 LLM 抽取输入。尤其是 Semantic Scholar 同名作者错配、Wikipedia 搜索错配非常明显，必须先做证据门控。

完整审计见：[60人证据审计矩阵.md](./60人证据审计矩阵.md)。

## 3. 对研究方法的修正

阶段一后续必须按以下顺序做：

```text
60 人名单
  → 自动抓取
  → 证据质量审计
  → A/B 级进入主分析
  → C 级只做背景参考
  → D 级先人工补源
  → 再做特征抽取与原子能力修订
```

不能直接把“抓到了的材料”当成真实画像。对每个人至少要记录：

| 字段 | 用途 |
|---|---|
| 可用来源 | 哪些来源能支持判断 |
| 错配风险 | 是否存在同名、搜索漂移、机构错配 |
| 证据等级 | A/B/C/D |
| 可进入的分析用途 | 主分析、背景参考、暂缓、需补源 |

## 4. 原子能力 V1.1 修订结论

本轮不是简单沿用旧的 16 个原子能力，而是对它们做了四类处理。

| 处理 | 原子能力 | 理由 |
|---|---|---|
| 保留 | 问题嗅觉、理论/机制深度、系统性思维、反共识判断、实验与评估品味 | A/B 级人物的论文、项目、访谈、组织方向中反复可见 |
| 保留 | 代码/系统实现力、速度/迭代节奏、产品化/场景定义 | 工程型、创业型、产业转化型路径都需要 |
| 改名 | 自我更新速度 → 跨范式迁移与自我更新 | “速度”容易误解为追热点；真正要观察的是跨模型、跨任务、跨组织阶段的迁移 |
| 改名 | 表达与解释力 → 技术表达与解释力 | 与企业家式外部叙事区分开 |
| 扩展 | 社区与生态参与 → 社区/生态建设 | 不只看开源，也看课程、标准、开发者生态、产业生态 |
| 新增 | 数据/算力/基础设施杠杆 | AI 领军者常通过数据、算力、平台和基础设施放大技术判断，这在旧框架中不够清楚 |
| 新增 | 外部叙事与信任建立 | 创业者、组织负责人、生态建设者需要让投资人、客户、社区和人才相信方向 |
| 降级 | 复现与调试力 | 对学生培养非常重要，但在名人公开材料中常不可见，不适合作为阶段一名人画像主尺度 |

因此，V1.1 核心原子能力从旧版 16 项调整为 17 项；“复现与调试力”不删除，而是放入阶段二学生过程证据项。

完整修订说明见：[原子能力修订说明_V1.1.md](./原子能力修订说明_V1.1.md)。

| 智识判断 | 反共识判断 | 保留。长期突破型和范式切换型人物高频出现 |
| 智识判断 | 实验与评估品味 | 保留。AI 领域强区分度维度 |
| 工程与产品 | 代码/系统实现力 | 保留。工程系统型和产业型路径关键 |

| 工程与产品 | 产品化/场景定义 | 保留。覆盖创业者和产业转化路径 |

## 6. 对阶段二的影响

阶段二不应直接给学生打总分，而应使用 V1.1 做数据覆盖测试：

1. 选 5-10 名真实学生，整理已有材料。
2. 对 17 个核心原子能力逐项标注“有证据 / 弱证据 / 无证据 / 需补采”。
3. 单独记录“复现与调试力”作为过程证据项，因为它对学生培养很重要，但不是名人公开画像中稳定可见的主尺度。
4. 判断哪些能力在学生培养期可观察，哪些需要新增低负担采集机制。
5. 基于学生数据覆盖情况，再形成 V2。

阶段二的核心问题不是“学生像不像某个名人”，而是：

```text
这个学生目前的证据，更接近哪类领军路径？
哪些关键能力已有强证据？
哪些能力不是弱，而是根本没有数据？
下一阶段应补什么项目、训练或观察材料？
```

## 7. 当前结论

阶段一 V1.1 的最重要结论是：

1. 旧版 16 个原子能力不能原样使用，需要改成 17 个核心原子能力 + 1 个学生过程证据项。
2. 自动抓取材料必须先做证据审计，尤其不能信任未校验的 Semantic Scholar 和百科搜索结果。
3. 企业家型、组织型 AI 领军人才不能只靠“领导力”概括，至少要拆成愿景、人才、资源、外部信任四类证据。
4. AI 领域相对于一般人才画像的特殊性，集中在实验评估、迭代速度、数据/算力/基础设施杠杆、跨范式迁移、社区/生态建设。
5. 下一步真正有价值的是把 V1.1 拿到学生材料上做覆盖测试，而不是继续凭感觉扩写量表。
