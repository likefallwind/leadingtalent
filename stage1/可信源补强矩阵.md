# 可信源补强矩阵

本文件用于修正阶段一的数据质量问题。上一版自动抓取暴露出大量同名错配，尤其是 Semantic Scholar 和 Wikipedia 搜索结果。因此，本轮不再把自动抓取结果直接作为可信证据，而是为 60 人逐一补充人工可信源。

对应机器可读数据见：`scrape/data/manual_sources.csv`。

## 1. 补强原则

可信源优先级如下：

| 优先级 | 来源类型 | 用途 |
|---|---|---|
| S1 | 官方个人主页、大学/公司/机构主页、IR/治理页面 | 确认身份、角色、长期贡献 |
| S2 | 官方项目、论文、GitHub 组织、产品文档 | 确认作品、工程系统、生态影响 |
| S3 | 奖项、听证证词、交易所文件、权威媒体人物稿 | 补充组织影响、战略选择、外部叙事 |
| S4 | Wikipedia / 搜索结果 / 未校验数据库 | 只做导航，不直接进入画像判断 |

本轮处理规则：

1. Semantic Scholar 错配源全部隔离，不再用于人物事实判断。
2. Wikipedia 只作为导航源，不作为核心证据。
3. 每个人至少补充两个可信来源；只有一个来源时不进入主分析。
4. 对创业者和工业领军人物，必须至少有一个公司/机构/产品/项目源。
5. 对学术人物，必须至少有一个机构主页、个人主页、奖项或论文/项目源。

## 2. 补强后质量结果

| 等级 | 人数 | 含义 |
|---|---:|---|
| A | 26 | 至少 3 类可信来源，适合做尺度校准样本 |
| B | 34 | 至少 2 类可信来源，适合进入主分析但保留置信度 |
| C | 0 | 不再保留仅单源样本 |
| D | 0 | 不再保留无可靠来源样本 |

这不是说 60 人材料“同样充分”。A 级更适合提炼行为锚点；B 级可以参与路径覆盖和反例检查，但不单独决定原子能力。

## 4. 对研究结论的约束

补强后，阶段一可以继续研究，但结论必须遵守三个约束：

1. **A 级样本主导尺度校准。** B 级样本主要用于路径覆盖、反例检查和补充企业家/工业路径。
2. **人物事实只能来自可信源。** 被隔离的自动错配源不能进入画像抽取。
3. **结论必须带证据类型。** 每个原子能力结论要说明来自论文/项目/组织/产品/叙事/团队中的哪类证据。
