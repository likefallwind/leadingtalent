# 阶段一可信研究结论 V1.2

## 1. 结论基础

V1.2 不再基于自动抓取的原始质量结论，而是基于补强后的可信源矩阵。

数据状态：

| 项 | 结果 |
|---|---:|
| 全名单人数 | 60 |
| 已生成人物 profile | 60 |
| 已补充人工可信源 | 60 |
| A 级可信源样本 | 26 |
| B 级可信源样本 | 34 |
| C/D 级样本 | 0 |

使用规则：

| 样本等级 | 用途 |
|---|---|
| A | 用于原子能力校准和行为锚点提炼 |
| B | 用于路径覆盖、反例检查、补足创业/工业人物 |
| C/D | 不进入分析 |

因此，V1.2 是当前唯一保留的阶段一研究结论，但仍不是终版量表。它是“可进入学生数据映射”的阶段一结果。

## 2. 可信结论一：AI 领军能力不是单一优秀，而是五类能力组合

补强后 60 人样本显示，AI 领军人才至少由五类能力共同构成：

| 能力簇 | 作用 |
|---|---|
| 智识判断 | 判断什么问题值得做，什么路线有长期价值 |
| 工程与产品 | 把方法、模型、系统、数据、算力转化成可运行能力 |
| 内驱成长 | 在长周期、范式变化和失败中持续演化 |
| 外向影响 | 让知识、工具、社区、客户和公众理解并采用 |
| 组织领导 | 牵引人才、资源和议程，形成组织级成果 |

这意味着，画像不能只看论文、代码、创业经历或职位头衔中的任何单项。

| 原子能力 | 置信度 | 结论 |

| 系统性思维 | 高 | 贯穿研究路线、工程架构、平台建设和组织管理 |
| 反共识判断 | 中 | 在突破型人物中显著，但不是所有领军路径都必须高 |
| 实验与评估品味 | 高 | AI 领域强区分度能力，尤其适合学生培养期观察 |
| 代码/系统实现力 | 高 | 工程系统、开源项目、平台产品中稳定可见 |
| 速度/迭代节奏 | 中 | 重要，但需要时间线证据；不能用“产出多”替代 |
| 产品化/场景定义 | 高 | 创业型、产业转化型、平台型人物中稳定可见 |

| 社区/生态建设 | 高 | 不限开源，也包括课程、开发者生态、标准和产业共同体 |

| 人才吸引与团队构建 | 高 | 领军者区别于个人优秀者的关键维度 |
| 资源整合与关键决策 | 高 | 在创业、平台、研究院和工业路径中稳定可见 |

## 4. 可信结论三：复现与调试力不应作为名人画像核心尺度

`复现与调试力` 对博士生成长非常关键，但在名人公开材料中不稳定可见。

因此 V1.2 的处理是：

| 位置 | 处理 |
|---|---|
| 名人画像核心尺度 | 不纳入 |
| 学生培养期画像 | 单独作为过程证据项记录 |
| 评价方式 | 看复现报告、issue、PR、debug 记录、配置说明、实验对照 |

这能避免一个常见误判：因为名人公开材料看不到某项能力，就误以为它不重要。

## 5. 可信结论四：领导力必须拆成四个可证据化变量

补强后创业者、研究院负责人、工业技术负责人和生态组织者样本都支持一个判断：不能把“领导力”作为单个大词打分。

应拆成：

| 变量 | 观察证据 |
|---|---|
| 愿景与议程设定 | 使命、研究纲领、产品路线、长期战略 |
| 人才吸引与团队构建 | 核心成员、共同作者网络、团队扩张、强人才加入 |
| 资源整合与关键决策 | 融资、算力、数据、合作、路线转向 |
| 外部叙事与信任建立 | 投资人/客户/社区/开发者/公众是否愿意相信和投入 |

这四项合在一起，才构成可研究、可观察、可校准的组织领导能力。

## 6. 可信结论五：AI 领域需要单独看“基础设施杠杆”

补强后样本显示，AI 领军者和一般科研/创业人才的一个重要差异，是能否把数据、算力、模型、平台、工具链和组织节奏组合成复利系统。

这项能力不能只放在“资源整合”里，因为它不是一般意义上的资源多，而是技术判断和资源结构高度耦合：

| 层面 | 观察方式 |
|---|---|
| 数据 | 是否理解数据质量、规模、分布和任务能力之间的关系 |
| 算力 | 是否知道何时扩大训练、何时优化效率、何时控制成本 |
| 平台 | 是否建设能持续复用的训练、评测、部署、开发工具链 |
| 组织节奏 | 是否让团队围绕基础设施形成更快迭代 |

因此 `数据/算力/基础设施杠杆` 应作为 AI 领域核心原子能力保留。

## 7. V1.2 archetype

补强后，阶段二可以先用以下 archetype 做相似度坐标，而不是固定分类。

| Archetype | 高权重能力 |
|---|---|
| 学术基础突破型 | 理论/机制深度、长期专注、反共识判断、实验评估品味 |
| 工程系统型 | 系统性思维、代码/系统实现力、基础设施杠杆、速度/迭代节奏 |
| 技术解释与教育型 | 理论/机制深度、技术表达与解释力、社区/生态建设 |
| 创业平台型 | 愿景与议程设定、人才吸引、资源整合、产品化、外部信任 |
| 学术产业转化型 | 问题嗅觉、产品化/场景定义、资源整合、团队构建 |
| AI 安全/治理议程型 | 反共识判断、愿景议程、技术表达、外部叙事 |
| 中国本土产业生态型 | 产品化、基础设施杠杆、资源整合、社区/产业生态建设 |

学生画像应输出“更接近哪些 archetype，以及缺哪些证据”，不应输出单一标签。

## 8. 可以进入阶段二的结果

阶段二可以使用：

1. 17 个核心原子能力；
2. 1 个学生过程证据项：复现与调试力；
3. A/B 证据质量分层；
4. 7 类 archetype 相似度坐标；
5. “能力水平”和“证据充分度”分开记录的输出格式。

```text
哪些维度在学生场景中需要合并、拆分或删除？
```
