# 陈天奇（Tianqi Chen）

## 基本定位

陈天奇是卡内基梅隆大学（CMU）机器学习系与计算机系助理教授、NVIDIA Distinguished Engineer，机器学习系统（ML Systems）与深度学习编译方向的代表人物 [A]。他在 60 人名单里补的是一类此前几乎缺席的极端形状——**纯粹的"工具·框架·平台型"建设者**：一个人接连创造了 XGBoost、（共同创造）MXNet、Apache TVM、MLC-LLM 四个被广泛使用的开源系统，把"让机器学习模型更轻、更快、更易部署"做成贯穿十余年的清晰技术主线 [A]。他的影响力主要不是来自头衔（年资尚浅，无院士/Fellow），而是来自**别人用脚投票的行为性指标**：开源 star、被引、工业采用。

## 学术与原创：一篇 8 万引的工程论文

陈天奇本科与硕士出自上海交通大学俞勇的 ACM 班，2013–2019 在华盛顿大学 Paul G. Allen 计算机学院读博，导师 Carlos Guestrin [A]。读博期间他与导师发表的《XGBoost: A Scalable Tree Boosting System》（KDD 2016）是机器学习被引最高的论文之一——Google Scholar 单篇约 **81,536 次引用**（截至 2026-06）[A]。这篇论文提出稀疏感知分裂查找与加权分位草图等系统级优化，使梯度提升树在数十亿样本规模上可扩展，长期统治 Kaggle 与工业界结构化数据建模。他的 Google Scholar 总引用约 **116,296**、h-index 47（主要由 XGBoost 单篇拉动）[A]。

2018 年他作为第一作者发表《TVM: An Automated End-to-End Optimizing Compiler for Deep Learning》（USENIX OSDI 2018），**开创了"深度学习编译（ML Compilation）"这一研究方向**，用基于学习的代价模型自动优化算子代码，实现跨硬件后端的模型部署 [A]。

## 系统与框架：四个高 star 开源项目

陈天奇的标志是开源系统本身：

- **XGBoost**（github.com/dmlc/xgboost，约 28.5k stars）——工业界事实标准的梯度提升库，支持 Python/R/Java/Scala/C++ [A]。
- **Apache TVM**（github.com/apache/tvm，约 13.5k stars）——Apache 顶级项目，跨硬件深度学习编译栈 [A]。
- **MLC-LLM**（github.com/mlc-ai/mlc-llm，约 22.8k stars）——通用大模型部署引擎，让 LLM 通过 ML 编译跑在浏览器、iPhone 等各类设备上 [A]。
- **MXNet**——最早的深度学习框架之一，由 DMLC 团队共同创造，曾被 AWS 选为官方深度学习框架（他是共同创作者，非单人）[A]。

他还是 **DMLC（Distributed Machine Learning Community）开源组织的联合发起人**，这个社区孵化了 XGBoost、MXNet 等一系列早期分布式 ML 工具 [A]。

## 公司与组织：从 TVM 到被 NVIDIA 收购

2019 年，他与 Luis Ceze、Jason Knight、Jared Roesch、Thierry Moreau（UW TVM 团队）共同创立 OctoML（后更名 OctoAI），把 TVM 技术栈商业化为模型部署/推理平台，他任首席技术专家（Chief Technologist），CEO 为 Luis Ceze [A]。**2024 年 9 月，OctoAI 被 NVIDIA 收购**（金额各家媒体口径在约 1.65 亿至 2.5 亿美元之间），团队整体加入 NVIDIA，他出任 Distinguished Engineer [A][B]。这是一次以技术栈与团队为标的的收购，而非他亲自主导的资本/上市路径。

## 人才与生态

他在 CMU 开设并开放了《Machine Learning Compilation》课程与在线教材（mlc.ai），系统化普及 ML 编译知识 [A]。他担任 **MLSys Conference 理事会主席（Board President）并曾任 MLSys 2023 程序主席**，2025 年其团队的 FlashInfer（LLM 推理注意力引擎）获 MLSys 2025 最佳论文 [A]。XGBoost/TVM/MLC-LLM 三个项目各自维系着活跃的开源贡献者社区，是其生态影响力的主要载体。

## 在画像中的位置（建议，待 v4 重评）

按 9 维框架，陈天奇的形状预计是：**D2 工程产品化与 D7 教育开源标志级**（四个高 star 开源系统 + 开放课程 + MLSys 治理），**D1 原创奠基强项**（XGBoost 8 万引、开创 ML 编译方向），D4 资本有一次中等量级退出（OctoAI→NVIDIA），而 D3 机构、D5 硬件、D6 安全、D8 信念逆向、D9 拐点偏低。这是一个**"纯开源系统建设者"**的鲜明形状——与名单内创始人/院士/CEO 型都不同，正是名单此前最易遗漏的一类。正式分数等下一个统一重评批次（v4）。

## 边界

需诚实区分角色：XGBoost 是他主导的一作工作；但 **MXNet、MLC-LLM 是 DMLC/团队作品**，不可写成单人独造；OctoAI 他是 CTO 级技术主导而非 CEO。OctoAI 收购金额媒体口径不一，标为区间。他年资尚浅，目前**无院士/Fellow 等重型荣誉头衔**——这恰好说明"领军"可以由行为性指标（star/被引/采用）而非声誉性头衔来确立，是一个有判别价值的形状。
