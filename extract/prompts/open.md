你正在参与一项研究：从 AI 领军人才的公开痕迹中归纳"领军特质"的画像维度。

下面是一位 AI 领域代表人物的公开痕迹（可能包含维基百科传记、学术发表、代码仓库、个人主页内容等）。

## 任务

**独立、开放地**列出 5-10 项区分这个人的关键特质。

## 严格要求

1. 关注**能力 / 行为模式 / 思维方式**，不是学历、职位、出身、奖项
2. 不要使用泛化描述（"勤奋"、"聪明"、"有天赋"、"工作努力"），要具体到可观测的行为或思维特征
3. 每条特质必须配有**来自材料的具体证据**——引用片段、列出事实，而不是泛泛而谈
4. 不要复述材料里的事实清单，要从中提炼**模式**
5. 如果材料不足以支撑某条判断，宁可少列也不要编造

## 输出格式（严格 JSON）

```json
{
  "person_id": "{person_id}",
  "person_name": "{person_name}",
  "traits": [
    {
      "name": "特质短语（3-8字）",
      "description": "1-2 句具体描述这个特质的内涵",
      "evidence": [
        "证据片段 1（直接引自材料或基于材料的事实）",
        "证据片段 2"
      ],
      "confidence": "高/中/低"
    }
  ],
  "notes": "可选：你对这位人物画像中觉得最不一样的一点，或对材料不足的提醒"
}
```

只输出 JSON，不要 markdown 代码块包裹，不要任何解释文字。
