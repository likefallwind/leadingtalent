# AI 领军人才画像研究协议

## 研究目标

本研究要回答的问题是：人工智能领域的领军人才到底呈现出什么样的画像。

这里的“画像”不预设为少数几个大维度，而是从公认领军人物的公开资料中抽取可核验事实，再从事实中归纳出更细的“原子能力”。原子能力积累到足够数量后，再做聚类、命名和结构化解释。

## 反模式

本研究明确避免以下做法：

| 反模式 | 风险 |
|---|---|
| 先设定几个大维度再让 AI 分类 | 后续资料会被迫强化预设维度，遗漏反常但重要的能力 |
| 依赖单个专家拍脑袋判断 | 容易受个人经验、圈层和已有叙事影响 |
| 用“学术型/产业型/中国本土”等粗标签替代证据 | 标签会给模型强引导，压低真实差异 |
| 只看成就结果，不看形成路径 | 会把资源、组织、时代窗口误判为个人能力 |
| 只看传记，不看论文、产品、组织和生态证据 | 容易得到空泛的人格描述 |

## 基本单位

研究中分四层记录信息：

| 层级 | 定义 | 示例 |
|---|---|---|
| 原始资料 | 可追溯来源中的文本、访谈、论文、官网履历、产品发布、组织资料 | 官方主页、论文、访谈、公司公告 |
| 原子事实 | 从资料中拆出的单一事实，不带解释 | “Hinton 2013-2023 年在 Google 兼职工作” |
| 原子能力 | 由一组事实支持的可迁移能力描述 | “能在非共识阶段长期坚持技术路线” |
| 能力簇 | 多个原子能力经过聚类后形成的高阶结构 | “长期技术信念与反共识坚持” |

## 资料优先级

| 等级 | 来源类型 | 用途 |
|---|---|---|
| A | 个人官网、大学/公司官方页面、论文、专利、产品发布、正式简历 | 事实锚点 |
| B | 权威媒体长文、访谈、会议演讲、公开演讲文字稿 | 路径、动机和决策线索 |
| C | 二级百科、行业报告、新闻汇总 | 补充线索，不能单独支撑强结论 |
| D | 社交媒体、论坛、未署名文章 | 只作为线索，不作为结论依据 |

## 抽取原则

1. 每个原子能力必须能回到至少一条原子事实。
2. 原子能力应该尽量细，不要直接写成“大局观”“领导力”“创新能力”。
3. 能力表述要能区分人物。例如“会做研究”太粗，“能把冷门理论路线推进到可规模化工程范式”更可用。
4. 保留负例和反常例。比如有人不是论文型领军者，而是资源组织、产品转化或平台生态型领军者。
5. 能力命名先临时化，等样本增加后再合并同义项。

## 抽取流程

1. 建立人物登记表：姓名、常用英文/中文名、当前/曾任关键机构、代表成果、资料入口。
2. 对每个人收集至少 5 类资料：官方履历、代表论文/项目、访谈或演讲、组织/公司材料、第三方长文。
3. 将资料拆成原子事实，避免解释混入事实。
4. 从事实中提取原子能力，每条能力记录证据来源和置信度。
5. 每 10-15 人做一次初步聚类，允许能力簇反复改名。
6. 完成全名单后做跨人对照：高频能力、稀有但高杠杆能力、地域/时代/机构差异、路线差异。

## 初步样本策略

第一轮不直接跑完整名单，而是选取能覆盖不同成功路径的人物做试抽取：

| 路径线索 | 样本人选 |
|---|---|
| 基础理论长期坚持 | Geoffrey Hinton、Yoshua Bengio、Richard Sutton |
| 大规模工程系统 | Jeff Dean、Ilya Sutskever、王海峰 |
| 数据集/基准塑造 | Fei-Fei Li、何恺明 |
| 组织与公司创建 | Sam Altman、Dario Amodei、梁文锋、杨植麟、张鹏 |
| AI for Science | Demis Hassabis、张林峰、鄂维南 |
| 开源生态与工具链 | 林达华、Andrew Ng、Andrej Karpathy |
| 治理与安全议题 | Stuart Russell、Nick Bostrom、Paul Christiano |

这些不是最终分类，只是为了让试抽取阶段覆盖不同资料类型。

## 预期产物

| 产物 | 说明 |
|---|---|
| 人物资料库 | 每个人的来源、原子事实、关键证据 |
| 原子能力库 | 100-200 条可复用能力项，带证据、人物、置信度 |
| 能力聚类图谱 | 从原子能力中归纳出的能力簇和路径类型 |
| 画像报告 | 回答“AI 领军人才是什么样子”，并说明不同类型之间的差异 |
| 方法审计 | 说明哪些结论来自证据，哪些只是暂时假设 |
