# 人工智能领军人才画像最终报告

## 结论摘要

本研究的最终结论是：

人工智能领域的领军人才，不是由身份、国别、职位、论文数量、公司规模或“学术型 / 产业型 / 创业型”这类预设标签定义的。

他们的共同点是：能够把某种资源转化为领域级杠杆，让其他研究者、工程师、学生、公司、投资者、开发者、政策制定者或产业组织开始以新的方式行动。

这个“资源”可以是：

- 一条长期技术路线。
- 一个结构或训练范式。
- 一个数据集、工具、教材或共同体入口。
- 一个企业平台、云平台、模型家族或开发者生态。
- 一个创业、资本、产品或物理世界入口。
- 一个科学问题、实验室组织或国家级基础设施。
- 一个 AI 芯片、推理硬件、端云协同或算力底座。
- 一个安全治理语言、可信 AI 路线或公共议题框架。

因此，AI 领军人才的画像不是“某几类人”，而是一组可证据追溯的高杠杆机制组合。

## 研究方法

本研究避免一开始预设大维度。实际流程是：

| 步骤 | 做法 |
|---|---|
| 1. 建立名单 | 使用第一批 60 人名单作为初始研究对象，并额外加入 AI 芯片 / 算力硬件边界对照样本。 |
| 2. 收集资料 | 优先使用官方主页、机构资料、论文、公司文档、技术报告和可信公开资料。 |
| 3. 抽取原子事实 | 不直接写“身份”，而是记录可被资料支持的事实。 |
| 4. 抽取原始能力 | 从事实中提取“这个人改变了什么行为链”。 |
| 5. 归并能力 | 把相近能力合并成可复用的 normalized capabilities。 |
| 6. 聚类机制 | 从能力中归纳机制，不从专家预设维度出发。 |
| 7. 审计边界 | 对容易混淆的机制做反向样本和边界审查。 |
| 8. 建立权重 | 不按频率简单排序，而是保留低频高杠杆机制。 |
| 9. 形成画像 | 输出可追溯、可解释、可继续补证的最终画像。 |

## 最终画像定义

AI 领军人才是能够形成“领域级行为改变”的人。

判断时不问：

| 不应优先问 | 原因 |
|---|---|
| 他是学术界、产业界还是创业者？ | 这是身份标签，容易把后续分析引向预设维度。 |
| 他是中国人、美国人还是其他国家的人？ | 国别不能解释机制，且中国样本内部差异很大。 |
| 他论文多不多？ | 论文数量不是领域级杠杆的充分条件。 |
| 他公司大不大？ | 公司规模可能来自资本、渠道、时机或行业结构，不等同于 AI 领军机制。 |
| 他能力覆盖数多不多？ | 能力数受资料厚度和抽取粒度影响，不能直接排名。 |

应优先问：

| 应该问 | 解释 |
|---|---|
| 他改变了谁的行为？ | 研究者、工程师、学生、开发者、公司、产业组织、政策制定者等。 |
| 他把什么资源变成了杠杆？ | 技术路线、平台、工具、组织、资本、产品、科学问题、安全语言、算力硬件等。 |
| 这个改变是否可被事实追溯？ | 必须能从资料、论文、产品、组织或平台证据追溯。 |
| 这个机制是否和相邻机制区分清楚？ | 防止把所有产业路径混成一个大类。 |
| 低频但是否不可替代？ | 防止 AlphaFold、安全公司、AGI 研究院、AI 芯片底座等低频路径被低估。 |

## 权重模型

本研究不按频率给机制排序，也不给人物打总分。

最终使用的机制权重规则是：

| 层级 | report_weight | 使用规则 |
|---|---:|---|
| core-high | 1.00 | 最终画像必须保留，是解释 AI 领军人才的主骨架。 |
| core | 0.90 | 正式画像应保留，但表达时可根据路径合并呈现。 |
| core-lowfreq | 0.85 | 低频但高杠杆，不能因样本少而删除。 |
| core-candidate | 0.75 | 进入画像，但必须带边界条件，暂不作为无条件主轴。 |
| important-high | 0.65 | 作为重要补充，能解释部分人物和路径。 |
| important | 0.55 | 有明确价值，但样本、证据或边界仍需补强。 |
| watch | 0.30 | 只作为观察项，不进入正式主画像。 |

这样处理有三个原因：

| 原因 | 说明 |
|---|---|
| 防止频率偏差 | 低频高杠杆机制可能极重要，例如 AlphaFold、安全导向公司、AGI 研究院、AI 芯片底座。 |
| 防止资料厚度偏差 | 公开材料多的人不等于机制更重要。 |
| 防止机制混并 | 云平台、智能硬件、企业基础设施、国家平台、AI 芯片和应用入口必须区分。 |

## 最容易犯的错误

| 错误 | 为什么错 | 应改成 |
|---|---|---|
| 先分学术型、产业型、创业型 | 这是身份分类，不是机制抽取。 | 先问他改变了什么外部行为。 |
| 把中国样本写成统一画像 | 中国样本内部高度异质。 | 按机制写，而不是按国别写。 |
| 把模型公司当成唯一主轴 | AI 领军机制还包括教育、工具、芯片、科学、安全、国家平台、视觉、机器人等。 | 保留完整机制谱系。 |
| 按能力数量排名 | 能力数受资料厚度影响。 | 看是否形成领域级杠杆。 |
| 把所有产业路径混在一起 | 云平台、硬件底座、产品入口、企业视觉、国家平台是不同机制。 | 用边界审计区分。 |
| 低估低频机制 | 低频机制可能不可替代。 | 保留 low-frequency high-leverage 路径。 |

## 如何使用这个画像

如果要判断一个新增人物是否具备 AI 领军人才特征，不应直接套标签。建议流程是：

| 步骤 | 问题 |
|---|---|
| 1 | 有哪些可证据化事实？ |
| 2 | 这些事实能抽出哪些原始能力？ |
| 3 | 这些能力改变了谁的行为？ |
| 4 | 这些行为改变映射到哪些机制？ |
| 5 | 机制是 core、core-candidate、important 还是 watch？ |
| 6 | 证据是 A、B 还是 C？ |
| 7 | 是否存在机制边界混淆？ |
| 8 | 这个人是否形成了领域级杠杆？ |

一个人不需要覆盖很多机制。单点高杠杆也可以构成领军人才特征。

## 最终判断标准

一个 AI 领军人才通常至少满足以下条件之一：

| 标准 | 说明 |
|---|---|
| 改变技术路线 | 让后续研究者开始采用新的模型、范式、训练方式或路线判断。 |
| 改变共同体工作流 | 让共同体开始用新的数据集、工具、基准、教材或开放平台工作。 |
| 改变人才入口 | 让大量新人以新的路径进入 AI。 |
| 改变组织生产能力 | 让公司、实验室、国家平台或研究院以新的方式组织 AI 能力。 |
| 改变产业转译路径 | 把研究、前史资源、产品窗口或资本生态转化为 AI 竞争力。 |
| 改变科学求解方式 | 让 AI 成为解决科学问题的新系统。 |
| 改变算力供给方式 | 改变训练、推理、部署的成本、延迟、规模或能耗结构。 |
| 改变安全与治理语言 | 让风险、可信、对齐和公共治理有新的概念框架。 |

## 最终结论

人工智能领军人才的画像不是一组身份标签，而是一组可以被事实追溯的领域级杠杆机制。

他们可能来自大学、公司、创业组织、投资机构、实验室、国家平台、开源共同体、芯片公司、科学研究组织或公共治理领域。但这些来源本身不是答案。

真正的答案是：

他们让 AI 领域中的其他人开始以新的方式研究、训练、部署、学习、投资、组织、治理、使用或扩展人工智能。

这就是本研究得到的 AI 领军人才画像。
