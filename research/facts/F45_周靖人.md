# F45 周靖人
> 阿里云 CTO；通义千问 Qwen / 开源大模型生态。活跃窗口 2010s–至今。证据深度：RICH

## FACTS
### 角色
- F1 [A] 阿里云智能 CTO，平台型技术领袖（非消费产品负责人）；负责让模型在云上训练/部署/微调/调用/评测/服务企业。
- F2 [A] 大模型是庞大技术栈（GPU 集群+训练框架+分布式调度+推理加速+安全治理+API/Agent/知识库），其工作是把这些组织成云上产品能力（阿里有 PAI 等 ML 平台底座）。
### Qwen 与开源
- F3 [A] 主导通义千问 Qwen 体系（LLM+多模态，文本/视觉/语音/音频）；Qwen3 强调混合思考/多语言/编码/数学/MCP Agent 能力。
- F4 [A] Qwen 非单一闭源 API 而是广泛开源生态，被大量开发者/创业公司/企业微调部署二次开发；通过开源提生态影响力、通过云服务承接企业部署推理需求。
### 社区与企业
- F5 [A] 推 ModelScope 魔搭社区聚合大量模型与开发者，降低使用门槛，成中国最大 AI 模型社区之一；"模型+社区+云平台"组合。
- F6 [A] 服务企业核心场景（知识库/客服/代码/风控/质检/政企），须解决安全/成本/私有化/稳定/合规——把模型能力变企业可用能力。
- F7 [A] 须在"模型能力/开源生态/云收入"三者间平衡（开源越开放直接收费越难、模型越强成本越高、企业越多定制越复杂）。
