## m06 当前定义

`m06 云 AI 与模型家族平台` 只在同时满足以下条件时成立：

| 条件 | 说明 |
|---|---|
| 外部可用 | 能被外部开发者、企业或行业客户调用、部署或二次开发。 |
| 平台栈 | 包含框架、模型家族、云服务、API、开发者生态、行业模型或配套工具链。 |
| 模型/AI 服务接口 | 不是单纯硬件、内部系统、内容产品或国家实验室。 |
| 可观察使用 | 至少有开发者、API、云服务、行业客户、开源社区或外部产品使用证据。 |

## 对 m06 是否升 core 的影响

当前建议：`m06` 继续保持 core-candidate，不升 core。

理由：

| 理由 | 说明 |
|---|---|
| 正例足够强 | Wang Haifeng、田奇、Zhou Jingren、黄学东支撑 m06 作为 core-candidate。 |
| 反向边界仍复杂 | Jeff Dean、陈天石、Zhang Yiming、高文都显示“平台/云/算力/应用”词汇容易误并。 |
| 定义可收窄 | m06 应限定为外部可用的云 AI、模型家族、框架、API、开发者和行业服务平台。 |
| 暂不宜升 core | 在完成剩余名单覆盖和正式权重模型前，把 m06 升 core 容易过度扩大产业平台路径。 |
