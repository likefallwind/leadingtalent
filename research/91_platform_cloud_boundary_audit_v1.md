## m06 是否应升级

当前判断：`m06 云 AI 与模型家族平台` 暂不在本文件中直接升级，但应在 v8 正式报告中重点审计是否从 important 升为 core-candidate。

支持升级的证据：

| 证据 | 说明 |
|---|---|
| 样本数增加 | Wang Haifeng 与田奇提供了强平台样本，Zhou Jingren 和黄学东此前已有支撑。 |
| 证据强度高 | 本轮与 m06 直接相关的新增能力多为 A 级。 |
| 外部行为清楚 | 开发者、API、云服务、框架、模型家族和行业模型都属于可观察外部行为。 |

暂不直接升 core 的原因：

| 原因 | 说明 |
|---|---|
| 与 m05 交叉 | 企业内部技术底座和对外云平台容易混在一起。 |
| 与 m19 交叉 | 公共研究机构的大模型生态和企业云模型平台需要区分。 |
| 与 m21 交叉 | 国家工程中心、标准和工业权威可能支撑云平台，但不是云平台本身。 |
