# AI 领军人才画像：自下而上的数据驱动研究

## 目标
不预设"领军人才应该长什么样"，而是从公认 AI 领军人物的**真实资料**出发（基线 60 人，v4 扩至 70、v5 扩至 **72 人**），
逐层涌现地得到画像。回答："领军人才到底是什么样子的？"——用证据说话，不拍脑袋。

## 数据
- 输入：`profiles/*.md`，60 人，每人 7–16KB 的深度资料（时间线、关键研究、产业经历、观点、荣誉、资料来源）。
- 本研究**只**从这些资料中提炼，不引入资料之外的主观印象。

## 六步流程（严格自下而上）
1. **原子事实（FACT）**：逐人，从资料中抽出可核验的硬事实（出身/师承、技术贡献、机构角色、
   关键决策与转折、失败与争议、数字、原话、荣誉）。每人 ~7–20 条（每条常打包多个子事实），
   贡献普查补全后全样本 569 条（普查前约 420 条）。→ `facts/F01–F60.md`
2. **原子能力（CAP）**：逐人，从该人的事实中归纳"他展示了什么能力"。每条能力**必须挂 `from F#`
   事实证据链**，可复核。允许几百条、允许重叠。全样本 498 条（普查前约 430 条）。→ 同文件 `## CAPS` 段。
3. **去重归并为规范能力库**：把这些原始能力**人工主题编码**地去重归并成 41 条规范能力
   （不使用任何预设维度词表；方法与局限见该文件末），每条带 维度/频率档/频率·60/代表人。
   → `capability_pool.md`
4. **建人×能力明账 + 折算维度分**：逐人把该人的能力对齐回 41 条规范能力（每条挂 `from F#`），
   登记成明账，再按明账里的折算规则得到 0–3 分。**每个分数都能下钻到能力与事实**。
   v2（2026-06）：60 人全部完成贡献普查后，按规则单次统一重评（29 人 39 处上调）。
   v3（2026-06）：拆分构念污染的原 D8 → **D8 信念逆向 + D9 拐点嗅觉 + 原型迁移二元标注**，成 9 维（只动 D8 列，明细见 `scores.md` 末）。
   v4（2026-06）：第二批 **F61–F70 共 10 位**完成新人入库普查后，按同一 9 维/41 能力 rubric **单次折入**（60→70 人，纯增量、老人分数不动；明细见 `scores.md` 末）。
   v5（2026-06，红队驱动）：先红队自攻（`validation/redteam_robustness.md`）打掉"零重合"伪头条，再做**相似性诱导对抗采样**——补 F71 Shazeer/F72 孙剑两个近克隆人单次折入（70→72，纯增量）。
   → `capability_matrix.md` + `scores.md`
5. **整合为画像**：9 维 = 雷达轴；画像 = 一块门槛地板 + 一张九维雷达，按共现归出 8 个**原型**（v4 新增「工具·框架·平台型」）。
   → `profile/portrait.md`
6. **真人验证**：拿名单内外的真实人物逐一走查，检验画像是否"既能解释、又能区分、又不万能套用"。
   → `validation/validation.md` + `validation/negative_sample/`（近名单未入选者对照组）

> 报告入口：`FINDINGS.md`（一页纸结论）/ `report.html`（交互式：能力频率分布 + 雷达 + 能力池浏览）。

## 数据求全层：完整主要贡献清单

`research/contributions/` 是对第 1 步（FACT）的**前置加固**：在抽事实之前，先用统一的来源清单
**穷举**每个人的主要贡献（八类维度，逐条带来源与影响规模），让 facts/scores 坐落在更全、更可比的
事实集上。评分不公的根源是各人被挖掘的广度/深度不一致（如 F31 刘铁岩早期漏了 LightGBM）。
本层由 `contribution-census` skill（`.claude/skills/contribution-census/`）标准化穷举执行，
**只采集+回填事实、不改正式分**；满 60 人后再统一重评。详见 `research/contributions/README.md`。

## 实验层：规范能力证据账本

`research/evidence/` 是对第 4 步的加固试点：不直接判断某人 `D1-D8` 强弱，而是逐人扫描
`capability_pool.md` 中的规范能力 ID，给出 `confirmed/partial/insufficient/not_found/contested`
判定、事实引用、角色强度、影响范围、限制条件和置信度。

这层目前**不改动** `capability_matrix.md` 与 `scores.md` 的正式分数，只用于暴露边界问题：
哪些命中其实只是 `partial`，哪些分数缺少更硬事实，哪些规范能力定义可能需要调整或新增。

## 标注约定
- FACT 标注：`[A]` 资料中明确陈述的硬事实；`[B]` 资料中陈述但表述较概括/需谨慎；不写资料之外的推断。
- CAP：每条 `— from F#,F#`，指向支撑它的事实编号。
- 第 3 步是**人工主题编码，不是算法聚类**；"41"与各频率均为分析者判断（±2~3 人误差）。
- 口径已定（v2，2026-06）：早期文档写"42 条"，实际可见 ID 一直是 41 条（T/B 4 条 + D 项 37 条）；
  v2 统一重评时核对后**正式定为 41**——属早期笔误而非缺口，普查补全的新 CAP 均可归入现有 41 条。
- **画像脊柱只有两层**：门槛地板（≈全员、不进雷达）+ 九维雷达（差异本身，v3 拆分原 D8 后）。早先的"区分层/四条轴"已弃用。
  结论建立在维度分数的**实际分布**上（见 `capability_matrix.md` 与 `FINDINGS.md`）：但"N 种形状零重合"经红队证明是统计必然（弱证据），主证据是 **PC1 仅 38% 方差(无主导轴)+宽云+原型真聚类(组内 0.70×)**；至 v5（72 人）仍无任一维全员高分。

## 偏差声明（与结论一并引用）
1. **幸存者偏差**：60 人全是成名者，无对照组。所得是"成名者的共同**相关**特征"，非成为领军的必要/充分条件。
2. **选样偏差**：名单偏向创始人 + 大厂科学家 + 院士，放大"建机构/撬资本/硬件创业"等能力。
   D3机构(v3 59/60、v5 71/72) 在低标准上近乎全员，很可能正是这种选样的产物。换一批名单分布会变。
   （注：v2 曾以为 D8预判 也 60/60 近全员，但 v3 拆分原 D8 后证明那是把"信念逆向"与"拐点嗅觉"两种反相关气质混算的**构念假象**——
   新 D8≥1 仅 40/60、D9≥1 仅 21/60（v5：52/72、30/72），均非全员。见 `scores.md` v3/v4/v5 变更记录。）
3. **来源偏差**：公开资料偏美化；FACT 已尽量只取硬事件，CAP 仍是归纳，故留证据链以便复核。
4. **名单循环性（构念入口偏差）**：`第一批60人名单.md` 无显式纳入标准，是**隐式行业共识提名**，
   等价于「资深从业者会脱口而出的那批人」。故本研究对象严格说是**「被行业广泛认可为领军者的一批人，
   在公开资料中呈现的能力结构」**，而非「领军本身」——存在「领军者认可领军者」的递归循环，
   无法在研究内部彻底打破（缓解路线见 `METHOD_IMPROVEMENTS.md`）。门槛尤其可能只是**提名者用的
   启发式信号**，而非领军的内在成因。
5. **媒体可见度 / 提名显著性偏差**（负样本实测支撑）：`validation/negative_sample/`（n=10）显示，
   8 维中**没有任何单维构成纳入的充分判别**——Oriol Vinyals（437k 引，D1/D2/D3 达标）仅因无创始人/
   资本身份(D4=0)而落选；Percy Liang 却**同时具备 D3(CRFM)+D4(Together AI $3.3B)+D6(HELM 治理)** 仍落选。
   两个相反方向的高分反例共同证明：达硬成果门槛后，纳入与否主要由**公众可见度/单一标志性叙事/提名显著性**
   决定，而非任何一条能力维度（含 D3/D4）。即"门槛特异度低"的范围已从 D1 实测扩展到 D3/D4。
   v3 扩到 n=10（含纯工具型 Loshchilov、有创业的 Neubig、非西方的刘群）后此结论稳健且跨地域一致——
   连"是否创业/是否有融资"都非充分项，盲区是结构性的（详见 `validation/negative_sample/README.md`）。
