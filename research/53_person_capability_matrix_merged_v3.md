## 矩阵观察

### 1. 高覆盖不等于更领军

当前 `nc_count` 受资料厚度和抽取粒度影响，不能直接当作人物排名。

| 类型 | 人物 | 说明 |
|---|---|---|
| 组合链条较长 | 朱松纯、Dario Amodei、周志华、张正友、Yan Junjie | 覆盖多条能力，通常说明其资料链条被拆得更细。 |
| 单点高杠杆 | Fei-Fei Li、Aidan Gomez、Kaiming He、Demis Hassabis、Zhang Linfeng | 能力数不一定多，但单点机制改变领域行为。 |
| 平台组织型 | Jeff Dean、Wang Haifeng、黄学东、高文、沈向洋 | 影响往往体现在组织、平台、标准和基础设施，而不是单一论文。 |

### 2. 中国样本内部差异很大

中国样本不能被统一概括为“中国本土 AI 人才”。

| 路径 | 代表 |
|---|---|
| 量化资源到基础模型 | Liang Wenfeng |
| 搜索产品经验到大模型助手 | Wang Xiaochuan |
| 清华知识资产到公司技术底座 | Tang Jie、Zhang Peng |
| 投资生态到大模型创业 | 李开复 |
| 长期机器学习共同体 | 周志华 |
| AGI 研究院 | 朱松纯 |
| 国家级技术标准和基础设施 | 高文 |
| 边缘 AI 与车载智能计算 | 余凯 |
| 大学-产业研究院桥接 | 沈向洋、Zhang Yaqin |

### 3. 产业路径已经拆出多个机制

产业路径不能再写成“商业化能力”。

| 产业机制 | 代表 |
|---|---|
| 研究资产到公司技术底座 | Tang Jie、Zhang Peng、Aidan Gomez |
| 前史资源迁移到 AI 竞争窗口 | Liang Wenfeng、李开复、沈向洋、余凯 |
| 创业叙事、资本接口与孵化生态 | Wang Xiaochuan、Yan Junjie、李开复 |
| 产品窗口与落地入口 | Yan Junjie、Yang Zhilin、Jiang Daxin、Zhang Peng、余凯 |
| 云 AI 与模型家族平台 | Zhou Jingren、黄学东 |
| 具身/车载/机器人智能平台 | 张正友、余凯 |

### 4. 安全路径至少有三种

| 安全机制 | 代表 |
|---|---|
| 安全治理共同语言 | Stuart Russell、Nick Bostrom、Paul Christiano |
| 安全导向前沿公司 | Dario Amodei |
| 单目标安全实验室 | Ilya Sutskever |

这三类不能合并成“安全型人才”。
