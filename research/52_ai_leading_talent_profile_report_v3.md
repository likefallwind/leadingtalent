# 人工智能领军人才画像报告 v3

## 报告定位

本报告回答的问题是：人工智能领域的领军人才画像是什么样的。

本报告延续当前研究方法：不先预设“学术型、产业型、创业型、中国型、美国型、安全型”等大维度，而是从人物资料中抽取事实，归纳原子能力，再聚类成机制画像，并用证据强度和权重模型约束结论。

当前结论基于：

| 数据层 | 当前规模 |
|---|---:|
| 名单人物 | 61 |
| 已抽取唯一人物 | 42 |
| 原子事实 | 296 |
| 原始能力 | 186 |
| 归并能力 | 125 |
| 主机制 | 28 |
| core 机制 | 16 |
| core-candidate 机制 | 3 |
| important 机制 | 9 |
| A 级证据能力 | 77 |
| B 级证据能力 | 48 |
| C 级证据能力 | 0 |

因此，这是一份当前最完整的阶段性画像报告，但仍不是最终封版报告。

## 一句话结论

AI 领军人才不是“某种身份的人”，而是“能把某种资源转化成领域级杠杆，并让领域中其他人开始以新方式行动的人”。

这里的资源可以是论文、模型结构、训练范式、教材、数据集、开源工具、云平台、投资生态、国家实验室、科学问题、安全框架、AGI 研究院、边缘芯片、车载计算或公共叙事。

这里的领域级杠杆指：他们改变了其他人做研究、训练模型、构建系统、投资创业、设计组织、部署产品、进入行业、评估风险、使用工具或讨论 AI 未来的方式。

| 权重建模 | 28 个主机制分为 core、core-candidate、important，不再等权处理。 |
| 产业/平台补样 | 加入李开复、黄学东、沈向洋、高文、余凯，使产业生态、云 AI、国家级基础设施、边缘/车载智能路径更清楚。 |

最重要的修正是：产业路径不能再写成简单“产品化”或“商业化”。当前证据显示，产业杠杆至少包括投资孵化、云平台、产业研究院、国家级基础设施、边缘 AI 和车载计算。

## 当前画像的核心定义

一个 AI 领军人才至少满足三个条件：

| 条件 | 说明 |
|---|---|
| 有可核验的前史资源 | 例如论文、模型、平台、教材、公司、研究院、标准、开源项目、云服务、投资生态或国家实验室。 |
| 能完成机制性转化 | 不是只有个人成就，而是能把资源转化成可被他人使用、学习、扩展、投资、治理或部署的机制。 |
| 能改变外部行为 | 其他研究者、工程师、学生、公司、政策制定者、投资者或产业组织因其工作改变行动方式。 |

这一定义避免把“职位高”“论文多”“公司大”“很有名”直接等同于领军。

当前研究特别需要避免一个误区：按频率给机制排序。

这些机制不一定高频，但一旦成立，会显著改变领域中的行动方式。

## v3 对“中国 AI 领军人才画像”的修正

当前证据强烈表明，不能写成“中国 AI 领军人才具有某种统一画像”。

中国样本内部至少有以下差异：

| 路径 | 代表 |
|---|---|
| 量化资源到基础模型 | Liang Wenfeng |
| 搜索产品经验到大模型助手 | Wang Xiaochuan |
| 清华知识资产到公司技术底座 | Tang Jie、Zhang Peng |
| 投资生态到大模型创业 | 李开复 |
| 长期机器学习共同体 | 周志华 |
| AGI 研究院 | 朱松纯 |
| 国家级技术标准和基础设施 | 高文 |
| 边缘 AI 与车载智能计算 | 余凯 |
| 大学-产业研究院桥接 | 沈向洋、Zhang Yaqin |

这些机制之间差别很大，用“中国本土”“产业型”“学术型”概括会造成误导。

## 当前最可靠的结论

当前可以较可靠地说：

1. AI 领军人才画像的主轴应是“改变了什么外部行为”，而不是“属于什么身份”。
2. 领军机制包括技术路线、结构范式、共同体工具、教育入口、企业平台、产业转译、安全组织、科学问题、国家级基础设施、AGI 研究院、边缘/车载智能平台和公共治理语言。
3. 产业路径不是单一“商业化能力”，而是投资、云、研究院、产品、车载计算、硬件融资和产业链的组合。
4. 安全路径至少有三类：共同语言、安全导向前沿公司、单目标安全实验室。
5. 中国样本内部机制差异很大，不能用单一中国画像概括。
6. 低频高杠杆机制必须保留，不能用频率替代重要性。

## 当前结论边界

这份 v3 报告仍有边界：

1. 61 人名单中已有 42 个唯一人物进入事实抽取，仍未覆盖全部名单。
2. 125 条归并能力已有证据审计，C 级为 0，但 B 级仍有 48 条需要继续补强。
3. `m08`、`m09`、`m28` 已完成边界审查，但本报告仍是 v3，尚未按 18 core / 1 core-candidate / 10 important 结构重写。
4. 已生成覆盖 42 人的完整合并版矩阵，但 m08、m09、m28 仍需边界审查。
5. 张亚勤、黄铁军、田奇、Wang Haifeng 等部分平台/产业人物仍可继续补证，用于验证平台和云 AI 机制。

## 最终表达

AI 领军人才的画像不是身份分类，而是机制组合。

他们之所以成为领军人才，是因为他们把某种资源转化为领域级杠杆：有人改变技术路线，有人改变共同体工具，有人改变人才入口，有人改变企业平台，有人改变资本和产品入口，有人改变前沿实验室组织，有人改变科学问题，有人改变国家级基础设施，有人改变 AGI/机器人/车载智能路径，有人改变风险和公共治理语言。

判断一个人是否是 AI 领军人才，关键不是看他属于哪一类，而是看他是否让领域中的其他人开始以新的方式行动。
