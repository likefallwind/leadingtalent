# 人工智能领军人才画像报告 v6

## 报告定位

本报告是当前研究的最新阶段性结论。它基于 `74_person_capability_matrix_merged_v5.md`，将 v5 报告中的 `45 人 / 136 归并能力` 更新为 `47 人 / 144 归并能力`。

当前结论基于：

| 数据层 | 当前规模 |
|---|---:|
| 名单人物 | 61 |
| 已抽取唯一人物 | 47 |
| 原子事实 | 326 |
| 原始能力 | 206 |
| 归并能力 | 144 |
| core 机制 | 18 |
| core-candidate 机制 | 2 |
| important 机制 | 10 |
| watch 机制 | 3 |
| A 级证据能力 | 92 |
| B 级证据能力 | 52 |
| C 级证据能力 | 0 |

本报告仍不是最终封版报告。原因是名单尚未完全覆盖，并且 `m29 企业侧视觉 AI 基础设施` 虽已从 watch 升为 core-candidate，但仍需与 `m07`、`m19`、`m28` 做边界审查。

## 一句话结论

AI 领军人才不是由身份、国别、职位、论文数量或公司规模定义的，而是由其是否能把某种资源转化为领域级杠杆定义。

更具体地说：AI 领军人才是能让其他研究者、工程师、学生、公司、投资者、政策制定者或产业组织开始以新方式行动的人。

## m29 为什么升为 core-candidate

`m29 企业侧视觉 AI 基础设施` 已有三个相互补充的样本：

| person | 机制表现 |
|---|---|
| 朱珑 | YITU：视觉 AI、智能城市、智能医疗、AI 芯片和企业侧行业基础设施。 |
| 汤晓鸥 | SenseTime：高校视觉研究、AI 软件、行业标准、身份验证、视频内容基础设施和多场景扩展。 |
| 印奇 | Megvii：视觉研究院、Brain++/MegEngine、个人/城市/供应链 IoT、智能相机和物流系统。 |

这三个样本共同说明：计算机视觉不只是论文、算法或人脸识别产品，它可以成为企业侧行业基础设施，进入城市、医疗、身份验证、视频、IoT、供应链和物流系统。

## 当前结论边界

2. 144 条归并能力已有证据审计，C 级为 0，但 B 级仍有 52 条需要继续补强。
3. `m09b 投资孵化与 AI 创业生态形成` 仍是 core-candidate，需要更多样本。

5. 平台/云 AI 路径仍可继续补张亚勤、黄铁军、田奇、Wang Haifeng 等样本。

## 最终表达

AI 领军人才的画像不是身份分类，而是机制组合。

他们之所以成为领军人才，是因为他们把某种资源转化为领域级杠杆：有人改变技术路线，有人改变共同体工具，有人改变人才入口，有人改变企业平台，有人改变前史资源迁移，有人改变资本和产品入口，有人改变前沿实验室组织，有人改变科学问题，有人改变国家级基础设施，有人改变 AGI、车载智能和机器人路径，有人改变视觉 AI 基础设施，有人改变风险和公共治理语言。

判断一个人是否是 AI 领军人才，关键不是看他属于哪一类，而是看他是否让领域中的其他人开始以新的方式行动。
