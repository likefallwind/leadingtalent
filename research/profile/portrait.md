# 阶段四：整合为"AI 领军人才画像"

> 从 42 条规范能力（`capability_pool.md`）出发，逐人登记成 **人×能力明账**（`capability_matrix.md`），
> 折算出 **8 维 0–3 分**（`scores.md`），再整合成画像。
> 不是"一个领军人才长这样"，而是"领军人才这个群体，结构上长这样"。

---

## 一句话结论

**AI 领军人才不是一种人：60 人共享的只有两条硬门槛，群体内部的差异由一张八维雷达展开，呈多峰异质。**
60 人里有 **59 种不同的雷达形状**；任何想用单一画像（"远见+领导力+技术深度"）概括他们的尝试，都被数据本身否定。

---

## 脊柱 = 一块地板 + 一张八维雷达

整个画像只有两层结构，没有别的：

```
        ┌──────────────────────────────────────────────┐
 雷达    │  D1原创 D2工程 D3机构 D4资本                    │ ← 群体差异本身
（差异）  │  D5物理 D6安全 D7教开 D8预判                    │   每人 = 一组坐标/一个形状
        ├──────────────────────────────────────────────┤
 地板    │  ① 至少一件被公认硬成果（形态可替代）            │ ← 入场券，不进雷达
（≈全员）│  ② 长期·高强度·常含低潮期坚持的投入             │
        └──────────────────────────────────────────────┘
```

---

## 第一层：门槛（≈全员，是"入场券"，不进雷达轴）

把约 430 条能力去重归并后，**唯二接近全员**的不是任何性格/风格，而是两条硬通货：

1. **至少做出过一件被公认的"硬成果"**
   - 形态多样、可互相替代：奠基性论文 / 被沿用的架构或方法 / 大规模系统或平台 / 量产产品 / 行业标准 / 芯片 / 公司 / 经典教材。
   - **关键**：是"做出过一件"，不是"全都做"。Hinton 不做产品、Altman 不写论文、王兴兴不发顶会、Bostrom 不训模型——各自都有**自己那一件**。
2. **长期、高强度的投入**
   - 几乎每个人的资料里都能读到"在一个方向上以十年计的持续投入"，且常含**低潮期坚持**（Hinton 之于连接主义、Sutton 之于强化学习、周志华之于本土学派、余凯之于车规芯片）。

> **门槛的含义**：想进入这个群体，先得有"实打实的成果 + 长期投入"。
> 但这**只是入场券**——它无法解释这些人**彼此为何如此不同**。差异在雷达上。

---

## 第二层：八维雷达（群体差异本身）

群体内部的不同，就是每个人在这 8 个能力维度上的**形状**。每个人是一组**坐标**，不是某一维的极值。

| 维度 | 含义 |
|---|---|
| **D1 原创奠基** | 造基础件/方法/理论 |
| **D2 工程产品化** | 研究→量产/平台/大众产品 |
| **D3 机构组织** | 从零建并领导机构/公司、统管全局 |
| **D4 资本动员** | 撬动资本算力、设计资本结构、影响生态 |
| **D5 物理/硬件** | 芯片/机器人/具身/端侧/科学计算 |
| **D6 安全/思想** | 安全治理、可解释、范式命名与框架 |
| **D7 教育/开源** | 教材/课程/开源/师承谱系 |
| **D8 预判/逆向** | 逆向押注、捕捉拐点、选大问题、原型迁移 |

**从明账（`capability_matrix.md`）的 60 份分数直接算出的形态**：

| 维度 | 打到 3（标志级） | 得分≥2 | 得 0 分 | 形态 |
|---|:-:|:-:|:-:|---|
| D1 原创 | 28/60 | 49/60 | 3 | 高频但非全员标志 |
| D2 工程 | 12/60 | 39/60 | 9 | 中间堆积 |
| D3 机构 | 20/60 | 55/60 | 1 | **低标准近全员** |
| D4 资本 | 5/60 | 21/60 | 10 | 偏低、长尾 |
| D5 物理 | 5/60 | 11/60 | 34 | **强两极**（多数 0，少数顶满） |
| D6 安全 | 7/60 | 13/60 | 34 | **强两极** |
| D7 教开 | 19/60 | 32/60 | 11 | 分散 |
| D8 预判 | 11/60 | 39/60 | 0 | **低标准全员**（无人得 0） |

**读出三件事**：
1. **没有任何一维是全员的"标志级强项"**——打 3 分最多的 D1 也只 28/60（约一半），强烈多峰。
2. **每维两端都有人**——尤其 D5物理、D6安全，近 40 人落在两端（0 或 3）。
3. **诚实修正**：D8预判 60/60、D3机构 59/60 在**低标准**（≥1）上近乎全员——但这两维很可能被**名单选样放大**（名单全是创始人/首席/院士）。准确说：**没有全员的*强项*，个别维度只是在*低标准*上接近全员。**

> **维度独立性**：8 维大体各测各的（两两相关多在 ±0.3 内），**但有一对例外**——
> **D2工程 ~ D4资本 相关 +0.67**，二者其实是"产品/组织型"同一簇的两面，不算两根独立轴（见边界声明 4）。
> 另外，原创与组织/资本在数据上此消彼长（D1~D2 −0.44、D1~D4 −0.55）：**造基础件的人，往往不是撬资本/做产品化的人。**

## 少数特异能力（个别人独有，是"高分项"不是"选拔项"）

有些最被记住的特征，恰恰是**少数人独有**的，正因稀缺**不能写进通用画像**：

- **范式命名权**（D6.3，~9 人）：Bostrom"超级智能"、Sutton"苦涩教训"、朱松纯"小数据大任务"、张钹"第三代 AI"、鄂维南"AI for Science"——能给整个领域**起名字、定框架**的人极少。
- **一生多次原型迁移**（D8.4，~8 人）：Hinton/Bengio 奠基→安全；LeCun 奠基→统帅→再创业；汤晓鸥 科学家→创业→国家平台。这比任何静态特质更接近"领军内核"，但只有少数人做到。
- **诺奖级跨界**：Hassabis(AlphaFold→诺贝尔化学奖)、Hinton(→诺贝尔物理学奖)——可遇不可求。

> 这些是"高分项"而非"及格项"。用它们当选拔标准会犯**幸存者偏差**：它们解释"为何这几个人格外耀眼"，不解释"如何成为领军"。

## 由共现关系浮现的 7 个原型（一个人常同属 2–3 个）

把八维形状按共现聚一下，自然浮现 7 种原型。每个原型在**不同维度鼓起、不同维度塌陷**（模板形状见 `scores.md`）——这正是"多峰"的另一种表述。

| 原型 | 主导维度 | 典型人物 |
|---|---|---|
| **奠基型科学家** | D1+D7+D8 | Hinton, LeCun, Bengio, Sutton, Russell, 张钹, 鄂维南, 朱松纯, 周志华, 孙茂松, 何恺明 |
| **科学家–创业者** | D1+D3+D2 | Hassabis, 汤晓鸥, 张林峰, 唐杰, 印奇, 朱珑, 贾佳亚, Gomez, 杨植麟 |
| **产品/组织型领袖** | D2+D4+D8 | Altman, 雷军, 张一鸣, 王慧文, 王小川, 梁文锋, 闫俊杰, 姜大昕, 张鹏 |
| **巨头技术统帅** | D1~D3 均衡偏工程 | Jeff Dean, 沈向洋, 王海峰, 周靖人, 田奇, 张正友, 张亚勤, 黄学东, 李航 |
| **安全/思想型** | D6 一柱擎天 | Russell, Bostrom, Christiano, Olah, Amodei, Sutskever(SSI) |
| **传播/教育/开源型** | D7 顶满 | Andrew Ng, Karpathy, 孙茂松, 刘知远, 林达华, 黄铁军 |
| **物理世界/硬件型** | D5 突出 | 余凯, 陈天石, 王兴兴, 张正友, 印奇, 谢赛宁/张祥雨/颜水成(效率) |

**两点观察**：
1. **中美分布有结构差异**——"奠基型科学家""安全/思想型"以欧美为主；"产品/组织型领袖""科学家–创业者""物理世界/硬件型"在中国样本里更密集（与名单构成有关，见边界声明 2）。
2. **同一人常一生迁移原型**——这种"原型迁移能力"本身可能比任何静态特质更接近"领军内核"。

## 因果边界声明（最重要，必须与画像一并引用）

1. **这是"相关画像"，不是"因果配方"。**
   60 人全是已成名者，**没有对照组**。本画像回答"成名的 AI 领军者群体结构长什么样"，
   **不**回答"做到这些就能成为领军人才"。门槛尤其可能是**必要而远非充分**。

2. **名单构成决定了画像形状。**
   名单偏"创始人 + 大厂首席 + 院士"，所以"建机构/撬资本/巨头统帅/硬件创业"被放大，
   "纯理论数学家""默默无闻的关键工程师""开源社区无名贡献者"被系统性低估。
   D3机构、D8预判 在低标准上近乎全员，很可能正是这种选样的产物。**换一份名单，雷达形状会变。**

3. **运气、时代窗口与平台不可忽略，且本研究无法测量。**
   AlexNet 赶上 GPU+ImageNet，DeepSeek 赶上算力与开源拐点——**拐点本身不是个人能力**。
   把时代红利误读成个人特质，是这类研究最大的陷阱。

4. **8 维并非全部独立、打分是编码判断。**
   D2工程 与 D4资本 相关 +0.67，实为同一簇两面，不算两根独立轴。
   0–3 分由 `capability_matrix.md` 的折算规则得来，是**约定**不是客观测量，可质疑、可重定。
   但每分都可**逐层下钻**：分 → 命中的规范能力/CAP → `from F#` → `profiles/`。这就是"不拍脑袋"。

## 给"识别/培养 AI 领军人才"的可操作建议（谨慎使用）

- **不要按"理想画像"招人**——它不存在（59 种形状）。应按**八维定位**：这个岗位要的是 D1 创造者、D3 组织者，还是 D5 硬件型、D6 安全型？不同岗位答案不同。
- **门槛要严，风格要宽**：守住"硬成果 + 长期投入"，但**不要**用性格/风格/路径（海归/本土、论文/产品）筛人——数据显示这些恰恰是分散的。
- **看重"原型迁移"的潜力**：能在 D1原创 与 D2/D3/D4 组织端之间迁移的人（数据上这两端通常此消彼长），长期上限更高。
- **承认运气**：把平台、时代窗口、师承网络当作**结构性资源**去配置，而不是当作个人功劳去崇拜或苛责。
