# 人工智能领军人才画像报告 v8

## 报告定位

本报告是当前研究的最新阶段性结论。它在 v7 的基础上纳入平台/云 AI/国家工程边界批次，把报告口径从 `47 人 / 150 归并能力` 更新为 `48 人 / 160 归并能力`。

当前结论基于：

| 数据层 | 当前规模 |
|---|---:|
| 名单人物 | 61 |
| 已抽取唯一人物 | 48 |
| 原子事实 | 356 |
| 原始能力 | 226 |

| core 机制 | 18 |
| core-candidate 机制 | 3 |

| watch 机制 | 3 |
| A 级证据能力 | 102 |
| B 级证据能力 | 58 |
| C 级证据能力 | 0 |

本报告仍不是最终封版报告。原因是名单尚未完全覆盖，`m09b 投资孵化与 AI 创业生态形成` 仍需要补样验证，且 m06 虽已升为 core-candidate，但仍需继续审计它与 m05、m19、m21 的边界。

## 一句话结论

AI 领军人才不是由身份、国别、职位、论文数量或公司规模定义的，而是由其是否能把某种资源转化为领域级杠杆定义。

更具体地说：AI 领军人才是能让其他研究者、工程师、学生、公司、投资者、政策制定者或产业组织开始以新方式行动的人。

## m06 为什么升为 core-candidate

`m06 云 AI 与模型家族平台` 在 v8 中不再只是一个证据不足的 important 机制。新增材料显示，它可以被具体定义为：把框架、模型家族、云服务、开发者生态、API、芯片适配和行业应用组织成外部可使用的平台栈。

| 支撑样本 | 机制表现 |
|---|---|
| Wang Haifeng | PaddlePaddle、ERNIE、芯片适配、训练、推理部署、开发者社区、API 调用和产业链贯通。 |
| 田奇 | 华为基础研究成果、Atlas、MindSpore、开发者开放计划、Pangu-Weather 和科学计算行业系统。 |
| Zhou Jingren | 阿里云模型服务、Qwen/Model Studio 等云模型平台线索。 |
| 黄学东 | 微软语音、云 AI、产业平台和研发组织线索。 |

这说明云 AI 与模型家族平台不是单一产品，也不是单纯企业基础设施。它的关键是让外部开发者、企业、行业客户和模型应用者能在统一平台栈上训练、部署、调用或改造 AI 能力。

## m06 为什么暂不直接升 core

| 交叉机制 | 边界 |

| m19 国家级技术标准与 AI 基础设施平台 | m19 偏公共或国家级 AI 基础设施；m06 偏企业云和模型家族平台。 |
| m21 国家工程与工业技术权威 | m21 偏国家工程中心、标准组织和工业技术权威；m06 偏可被外部调用和使用的平台栈。 |

因此，m06 当前适合升为 core-candidate，但还不能直接升 core。

## 最终表达

AI 领军人才的画像不是身份分类，而是机制组合。

他们之所以成为领军人才，是因为他们把某种资源转化为领域级杠杆：有人改变技术路线，有人改变共同体工具，有人改变人才入口，有人改变企业平台，有人改变云与模型家族平台，有人改变前史资源迁移，有人改变资本和产品入口，有人改变前沿实验室组织，有人改变科学问题，有人改变国家级基础设施，有人改变 AGI、车载智能和机器人路径，有人改变视觉 AI 工具链、底层方法或企业基础设施，有人改变风险和公共治理语言。

判断一个人是否是 AI 领军人才，关键不是看他属于哪一类，而是看他是否让领域中的其他人开始以新的方式行动。
