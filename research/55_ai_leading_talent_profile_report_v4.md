# 人工智能领军人才画像报告 v4

## 报告定位

本报告是当前研究的最新阶段性结论。它基于 `54_core_candidate_boundary_audit_v1.md` 的边界审查结果，将 v3 报告中的 `16 core / 3 core-candidate / 9 important` 结构更新为：

| 机制状态 | 数量 |
|---|---:|
| core | 18 |
| core-candidate | 1 |
| important | 10 |

当前结论基于：

| 数据层 | 当前规模 |
|---|---:|
| 名单人物 | 61 |
| 已抽取唯一人物 | 42 |
| 原子事实 | 296 |
| 原始能力 | 186 |
| 归并能力 | 125 |
| A 级证据能力 | 77 |
| B 级证据能力 | 48 |
| C 级证据能力 | 0 |

本报告仍不是最终封版报告。原因是名单尚未完全覆盖，且 `m09b 投资孵化与创业生态形成` 仍需补样验证。

## 一句话结论

AI 领军人才不是由身份、职位、国别或单一成就定义的，而是由其是否能把某种资源转化为领域级杠杆定义。

更具体地说：AI 领军人才是能让其他研究者、工程师、学生、公司、投资者、政策制定者或产业组织开始以新方式行动的人。

## 对产业路径的最终修正

v4 明确把产业相关机制拆开：

| 机制 | 改变的外部行为 |
|---|---|
| m07 研究资产到公司技术底座 | 高校/研究机构成果如何进入公司技术栈。 |
| m08 前史资源迁移到 AI 竞争窗口 | 旧资源如何进入新技术周期。 |
| m09a 创业叙事与资本接口 | 融资、治理和资本市场如何围绕 AI 公司形成。 |
| m09b 投资孵化与创业生态形成 | 公司形成之前的投资、孵化和资源配置如何发生。 |
| m10 技术团队组装 | 模型公司如何建立可信研发起点。 |
| m11 产品窗口与落地入口 | 模型能力如何进入用户和产业场景。 |
| m28 具身/车载/机器人智能平台 | AI 如何进入汽车、机器人、边缘计算和物理世界。 |

这避免把不同机制混成“商业能力”或“产业能力”。

## 当前结论边界

1. 61 人名单中已有 45 个唯一人物进入事实抽取，仍有 16 人未覆盖。
2. 136 条归并能力已有证据审计，C 级为 0，但 B 级仍有 50 条需要继续补强。
3. `m09b 投资孵化与 AI 创业生态形成` 仍是 core-candidate，但已由李开复和王慧文共同支撑。
4. `m28 具身/车载/机器人智能平台` 已升 core，并由张正友、余凯、王兴兴共同支撑。
5. 朱珑样本提示 `watch-vision-infra 企业侧视觉 AI 基础设施`，需要补汤晓鸥、印奇、Lin Dahua 等视觉产业样本审查。

## 最终表达

AI 领军人才的画像不是身份分类，而是机制组合。

他们之所以成为领军人才，是因为他们把某种资源转化为领域级杠杆：有人改变技术路线，有人改变共同体工具，有人改变人才入口，有人改变企业平台，有人改变前史资源迁移，有人改变资本和产品入口，有人改变前沿实验室组织，有人改变科学问题，有人改变国家级基础设施，有人改变 AGI、车载智能和机器人路径，有人改变风险和公共治理语言。

判断一个人是否是 AI 领军人才，关键不是看他属于哪一类，而是看他是否让领域中的其他人开始以新的方式行动。
