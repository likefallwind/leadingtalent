# 完整主要贡献清单（Contribution Census）

> 目的：让每个人的资料**求全**，而不是零散补缺。每人一份 `F##_<name>.md`，按统一的八类维度
> **穷举**其主要贡献，逐条带来源与影响规模。这是 `profiles/` 与 `research/facts/` 之前的"全量底料"：
> profile 应反映清单里的全部主要贡献，facts 从清单提炼，scores 再坐落在更全、更可比的事实集上。

## 为什么需要这一层

整条流水线 `profiles → facts → capability_pool → capability_matrix → scores → portrait` 是
"垃圾进、垃圾出"。早期 profiles 深度不均：刘铁岩（F31）漏了 LightGBM，直接导致 `D1.1/D2.2` 被低估。
**评分不公的根源是"每个人被挖掘的广度/深度不一致"**——谁先被零散补全谁就暂时显得更强。
解决办法：每个人都被同一把尺子、同一套来源清单**穷尽式**搜过，把主要贡献都收全，深度可比。

本层由 `contribution-census` skill（见 `.claude/skills/contribution-census/`）标准化执行。

## 八类覆盖维度（每人逐类穷举，不只挑最有名的）

1. **学术**：代表论文 / 里程碑工作 / 高被引成果 / 开创性概念（带引用量、会议·期刊、年份）
2. **系统与框架**：开源框架、工具链、平台、基准/数据集（带 GitHub/PyPI、星标/下载/采用规模）
3. **产品与工程**：上线产品、产品线、技术系统（带用户/营收/规模证据）
4. **公司与组织**：创立/执掌的公司、实验室、研究院（带融资、上市、团队规模）
5. **标准与基础设施**：技术标准、芯片、算力平台
6. **学术服务与荣誉**：Fellow/院士/Turing/Nobel、最佳论文/Test-of-Time、重要委员会角色
7. **人才与生态**：师承谱系、培养的知名学生、社区/教育影响
8. **思想与公共影响**：著作、有影响力的观点/报告、政策与治理参与

某类对某人确实为空时，写一行"（本类无）"并说明已查过哪些来源——让"没有"是被记录的结论，而非默认空白。

## 条目 schema

每条贡献一行表格：

`贡献名 | 类别(八类之一) | 年份 | 来源URL + 来源层级 | 影响/规模(引用/星标/营收/用户) | 本人角色(独立/共同/团队/组织者) | 与现有facts关系(已覆盖/缺口待补/需更强来源)`

## 来源层级（沿用 coverage_audit.md §3 优先级）

本人/机构官方页 > 项目仓库 / 学术索引(Scholar/DBLP/Semantic Scholar) > 论文/报告 > 奖项官方页 >
大学/公司页 > 权威媒体 > 百科。权威媒体与百科用于交叉核对，**单独不作硬来源**。

## 与下游的关系（重要纪律）

- 本层**只采集 + 回填事实**，**不重算** `scores.md` / `capability_matrix.md` 的分数。
- 状态进入 `research/coverage_audit.md` 台账；只有 60 人全部到 `audited-v1`/`updated` 后，
  才做一次**统一重评**——避免"先审者先涨分"放大偏差。
- 偏差声明（见 `research/README.md` 末）仍然成立：求全只缩小"信息缺失偏差"，
  不消除幸存者/选样/来源偏差。
