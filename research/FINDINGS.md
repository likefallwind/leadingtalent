# AI 领军人才画像 · 核心结论（一页纸）

> 自下而上、不预设维度，从 60 人真实资料中得到的结论。完整链条可逐层下钻复核。
> 方法见 `README.md`；逐人事实/能力见 `facts/`；规范能力库见 `capability_pool.md`；
> **打分依据见 `capability_matrix.md`（人×能力明账）**；8 维评分见 `scores.md`；验证见 `validation/`。

## 做了什么
- **60 人** 深度资料（`profiles/*.md`）→ 经 `contributions/` 贡献普查补全后，逐人提 **569 条原子事实**（每条标 `[A]/[B]`+来源）
- → 逐人提 **498 条原子能力**（每条挂 `from F#` 证据链）
- → 人工主题编码**去重归并成 41 条规范能力**（非算法聚类，方法与局限见 `capability_pool.md` 末）
- → 逐人把能力对齐回 41 条、登记成 **人×能力明账**（`capability_matrix.md`），由命中情况**折算出 8 维 0–3 分**
- → 8 维 = 雷达轴；按共现归出 **7 个原型**
- → 用名单内外真人做**证伪式验证**
- → **v2（2026-06）**：60 人全部完成贡献普查后按规则**单次统一重评**（29 人 39 处上调，明细见 `scores.md` 末）；核心结论不变

> 每个分数都能下钻：`scores.md` 某分 → `capability_matrix.md` 看它命中哪几条规范能力 → `facts/F##.md` 的 `from F#` → `profiles/` 原始资料。

## 最重要的发现：领军人才不是一种人（有数据支撑）

从 60 人的八维分数直接算出来：

- **60 人里有 59 种不同的雷达形状**——几乎没有两个人长得一样（v2 重评后仍是 59；唯一重合对为杨植麟≡Gomez，两位"顶会奠基论文→基础模型公司创始人"确实路径同构）。
- **没有任何一维是全员的"标志级强项"**：打到 3 分最多的 D1原创也只 32/60、D3机构与 D7教开各 20/60，都约一半；越往高分越分散，强烈**多峰**。
- **每一维两端都有人**（都有人 0 分、也有人 3 分），D5物理（36 人）、D6安全（40 人）最两极。

所以**数据本身拒绝坍缩成"领军人才就该是 XX 样"的单一模板**。

> **诚实修正（做实之后才看见）**：并非"什么都不共有"。在**低标准**（≥1 分）上，**D8 趋势预判 60/60 全员都有一点、D3 机构组织 59/60**——这两维近乎人人沾边，但**很可能是名单选样的产物**（名单全是创始人/首席/院士，天然都在"组织点什么、押注点什么"）。准确表述是：**没有任何能力是全员的*强项*；个别维度只是在*低标准*上接近全员。**

## 画像结构：一块地板 + 一张八维雷达

1. **门槛（≈全员，不进雷达，是入场券）**——唯二接近全员的不是软特质，而是两条硬通货：
   - ① **至少做出过一件被公认的硬成果**（论文/架构/系统/产品/标准/芯片/公司/教材之一，形态可互相替代）；
   - ② **长期、高强度的投入**（常含低潮期坚持）。
2. **八维雷达（差异本身）**——群体内部的不同，就是各人在这 8 维上的**形状**：
   D1原创奠基 / D2工程产品化 / D3机构组织 / D4资本动员 / D5物理硬件 / D6安全思想 / D7教育开源 / D8预判逆向。
   一个领军者 = 一组**坐标**，不是某条的极值；每维都有人站两端。
3. **少数特异能力（个别人独有，是"高分项"不是"选拔项"）**：范式命名权（~10 人）、一生多次原型迁移（~8 人）、诺奖级跨界（Hinton/Hassabis）。稀缺，**不能写进通用画像**。

## 7 个原型（一个人常跨 2–3 个，且常一生迁移）
奠基型科学家 / 科学家–创业者 / 产品·组织型领袖 / 巨头技术统帅 / 安全·思想型 / 传播·教育·开源型 / 物理世界·硬件型。
> 7 个原型在不同维度鼓起、不同维度塌陷（模板形状见 `scores.md`）——这正是"多峰"的另一种表述。
> **"原型迁移能力"（如 Hinton 奠基→安全、LeCun 奠基→统帅→再创业）在数据上表现为一项稀缺的高分项；
> 但因 60 人全是成功者、无法观测"迁移失败者"，无法判断它是否具有选拔预测力——
> 不宜把它升格为"领军内核"，那会犯最严重的幸存者偏差。**

## 必须一并引用的边界
- **相关画像，非因果配方**：60 人全是成名者、**无对照组**，门槛很可能"必要而不充分"。
- **名单构成决定画像形状**：偏"创始人+大厂首席+院士"，放大了建机构/撬资本/硬件创业等能力的频率——这也是 D3机构、D8预判 在低标准上近乎全员的原因。
- **8 维并非全部独立**：D2工程 与 D4资本 高度相关（+0.70），实为"产品/组织"同一簇的两面，不算两根独立轴；另有一条"创造端 vs 经营端"负相关轴（D1/D6/D7 与 D2/D4 此消彼长，−0.3~−0.5）；其余两两相关 < ±0.3。
- **打分是分析者编码判断**：0–3 切分是约定（规则见 `capability_matrix.md`），可质疑、可重定；本研究保证的是"可复核"，不是"客观唯一"。
- **运气与时代窗口不可测且不可忽略**：别把平台红利误读成个人特质。

## 验证结论
画像通过四项检验：**能解释**（60 人都装得下）、**能区分**（差异极大的人落在相反坐标）、
**留出泛化**（黄仁勋/Schmidhuber/Suleyman 等名单外真人被准确定位且不漂移）、
**可证伪**（门槛必要不充分；任一"软特质"都被名单内反例击穿；非 AI 成功者被门槛挡在外）。
