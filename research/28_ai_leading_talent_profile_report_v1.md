# 人工智能领军人才画像报告 v1

## 报告定位

本报告回答的问题是：人工智能领域的领军人才画像是什么样的。

本报告不把领军人才预设为“学术型、产业型、创业型、中国本土、海外学者”等标签。当前方法是从人物资料中抽取事实，再归纳原子能力，最后聚类成机制画像。

当前结论基于：

| 数据层 | 当前规模 |
|---|---:|
| 名单人物 | 61 |
| 已抽取唯一人物 | 32 |
| 原子事实 | 231 |
| 原始能力 | 137 |
| 归并能力 | 84 |
| v2 机制簇 | 30 |
| A 级证据能力 | 48 |
| B 级证据能力 | 36 |
| C 级证据能力 | 0 |

因此，这是一份 `v1` 画像报告，不是最终封版报告。

## 核心结论

人工智能领军人才不是由身份、国别、职位或单一成就定义的，而是由其是否能把某种资源转化为领域级杠杆定义的。

这里的“领域级杠杆”指：他的工作改变了其他人做研究、训练模型、构建系统、进入行业、组织团队、配置资源、评估风险、开发产品或解决科学问题的方式。

换句话说，领军人才不是简单“能力强的人”，而是能改变领域行为的人。

## 总体画像

当前资料显示，AI 领军人才通常呈现为以下结构：

| 层级 | 说明 |
|---|---|
| 前史资源 | 他们通常带着某种强前史资源进入 AI：长期研究路线、模型结构、数据集、教材、开源工具、搜索产品经验、跨国研究机构经验、量化算力资源、云平台、研究院或科学计算方法。 |
| 核心杠杆 | 他们在某个机制上形成强影响：结构发明、任务基准、教育传播、工程平台、安全语言、科学问题、创业产品窗口等。 |
| 扩散机制 | 他们通过组织、平台、课程、论文、开源、公司、政策接口、开发者生态或资本市场把影响扩散出去。 |
| 领域改变 | 最终体现为别人开始沿着他的路线工作，使用他的工具，采用他的基准，学习他的课程，加入他的组织，使用他的平台，或围绕他的框架讨论问题。 |

## 六类高杠杆路径

从 30 个机制中，可以进一步抽象出六类常见高杠杆路径。注意这不是先验分类，而是当前数据中的归纳结果。

### 1. 改变技术路线

这类人物通过长期路线判断、基础方法积累、结构或训练范式发明影响领域方向。

代表机制：

| 机制 | 代表 |
|---|---|
| 长期技术路线判断 | Hinton、Sutton、LeCun |
| 结构与训练范式发明 | Goodfellow、Aidan Gomez、Kaiming He、Saining Xie |

这类人的关键不是“论文多”，而是他们让后续大量研究沿着某个新结构、新原则或新路线展开。

### 2. 改变共同体工作流

这类人物通过数据集、评测、工具链、教材、课程或解释材料改变别人怎么学习和做研究。

代表机制：

| 机制 | 代表 |
|---|---|
| 任务、基准与工具标准化 | Fei-Fei Li、Lin Dahua、Richard Sutton |
| 教育、解释与人才放大 | Andrew Ng、Karpathy、Olah |

这类能力容易被低估，因为它看起来像“传播”或“工具”，但实际改变了人才进入领域和研究复用的成本。

### 3. 改变工程和平台基础设施

这类人物把模型、框架、硬件、云、开发者生态和产业应用组织成平台。

代表机制：

| 机制 | 代表 |
|---|---|
| 企业基础设施平台 | Jeff Dean、Wang Haifeng |
| 云与模型家族平台 | Zhou Jingren |
| 开发者与企业生态平台 | Wang Haifeng |

这类领军者的影响不一定来自单个模型，而来自让组织长期拥有训练、部署和迭代 AI 的能力。

### 4. 改变产业和创业路径

这类人物把高校研究、前史资源、技术团队、资本、产品窗口和本土生态连接成公司。

代表机制：

| 机制 | 代表 |
|---|---|
| 高校知识资产到公司技术底座 | Tang Jie、Zhang Peng |
| 前史资源迁移到大模型竞争 | Wang Xiaochuan、Jiang Daxin、Liang Wenfeng |
| 技术团队组装 | Yang Zhilin |
| 创始人集中控制 | Yan Junjie |
| 产品窗口选择 | Yang Zhilin、Jiang Daxin、Zhang Peng、Yan Junjie |

中国大模型创业的关键不是“中国本土”这个标签，而是不同前史资源如何进入大模型窗口：搜索、微软研究、清华模型架构、量化算力、技术团队、国产芯片适配和产品入口。

### 5. 改变科学问题求解方式

这类人物把 AI 组织成科学发现工具，而不是只做通用聊天或互联网应用。

代表机制：

| 机制 | 代表 |
|---|---|
| 科学问题与 AI 系统验证 | Demis Hassabis |
| 科学智能组织议程 | Liu Tieyan、Weinan E |
| 科学模型与工具基础设施 | Zhang Linfeng |

AI for Science 不是“AI 应用”的简单子类，它涉及科学问题选择、数学/计算基础、模型方法、跨学科组织和工业 R&D 基础设施。

### 6. 改变风险、治理和公共接口

这类人物不一定通过模型性能领先，而是改变领域如何讨论风险、对齐、治理、部署和公众信任。

代表机制：

| 机制 | 代表 |
|---|---|
| 安全治理共同语言 | Russell、Bostrom、Christiano |
| 公司公共政策与监管接口 | Sam Altman |
| 前沿公司治理与组织韧性 | Sam Altman、Yan Junjie |

这说明 AI 领军人才画像中必须保留非工程型路径：概念框架、教材、研究组织、监管表达和治理韧性都可能成为领域级杠杆。

## 高频和高杠杆的区别

当前矩阵显示，高频不等于重要，低频也不等于边缘。

| 类型 | 例子 | 含义 |
|---|---|---|
| 高频但边界松 | 多重技术权威、公共影响 | 很多人跨组织形成影响，但需要进一步拆细。 |
| 低频高杠杆 | GAN、Transformer、ResNet、ImageNet、安全治理共同语言 | 少数人通过一个强机制改变大量后续行为。 |
| 中频但解释力强 | AI for Science、教育解释、企业平台 | 不一定人人具备，但能解释不同类型的领军路径。 |

## 对研究方法的反思

当前结果支持用户最初提出的担忧：如果一开始就让 AI 设几个大维度，很多关键机制会被压扁。

例如：

| 如果用粗维度 | 会漏掉的机制 |
|---|---|
| 创新能力 | 结构发明、任务定义、路线原则化、科学问题选择 |
| 领导力 | 创始人集中控制、实验室整合、国家级平台、公司治理韧性 |
| 产业能力 | 前史资源迁移、本土部署适配、产品窗口选择、资本接口 |
| 学术能力 | 教材标准化、公共议题叙事、开源工具链、教育人才放大 |

因此，更合适的画像方法是：先抽原子事实，再抽原子能力，再聚类机制，最后才写画像。

## 当前结论边界

这份报告仍有明确边界：

1. 61 人名单中只有 32 个唯一人物进入事实抽取。
2. 原 5 条 C 级能力已经补到 B 级，但仍不是强一手结论。
3. 部分中国创业者和平台人物仍依赖公开报道、行业资料和产品发布材料，缺少更多一手访谈。
4. 当前画像强调“形成领域影响的机制”，还没有形成量化权重。
5. 能力归并仍需要更多人物事实反向审计。

## 一句话结论

AI 领军人才的画像不是“某类身份的人”，而是“能把某种资源转化为领域级杠杆的人”：他们通过技术路线、结构范式、工具基准、教育传播、工程平台、产业转译、科学问题、安全治理或组织公共接口，改变了整个领域中其他人的行为方式。
