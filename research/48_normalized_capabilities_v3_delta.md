# 归并能力库 v3 增量：cap167-cap186

本文件将 `46_industry_platform_capability_map.md` 中的 `cap167-cap186` 归并为新的 normalized 能力。它接续 `35_normalized_capabilities_v2_delta.md`，编号从 `nc110` 开始。

## 增量归并规则

| 规则 | 说明 |
|---|---|
| 不按身份归并 | 不使用“投资人”“微软高管”“院士”“自动驾驶企业家”等身份标签。 |
| 保留产业机制差异 | 投资生态、云 AI、产业研究院、国家级基础设施、边缘/车载平台不合并成“产业能力”。 |
| 合并相邻事实链 | 同一人物中表达相近的能力合并，避免一个机制被拆得过碎。 |
| 接入权重模型 | 每条新增能力都标注对应的主机制或候选修正机制。 |
