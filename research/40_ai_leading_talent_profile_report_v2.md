# 人工智能领军人才画像报告 v2

## 报告定位

本报告回答的问题是：人工智能领域的领军人才画像是什么样的。

本报告仍然遵守当前研究的核心约束：不预设“学术型、产业型、创业型、中国型、美国型、安全型”等粗维度，而是从人物资料中抽取原子事实，再归纳原子能力，最后聚类成机制画像。

当前结论基于：

| 数据层 | 当前规模 |
|---|---:|
| 名单人物 | 61 |
| 已抽取唯一人物 | 37 |
| 原子事实 | 266 |
| 原始能力 | 166 |
| 归并能力 | 109 |
| 候选机制簇 | 36 |
| A 级证据能力 | 66 |
| B 级证据能力 | 43 |
| C 级证据能力 | 0 |

因此，这是一份比 v1 更强的阶段性画像报告，但仍不是最终封版报告。

## 一句话结论

人工智能领军人才不是“某种身份的人”，而是“能把某种资源转化为领域级杠杆的人”。

这里的资源可以是技术路线、模型结构、数据基准、教材、课程、开源工具、云平台、实验室、公司治理、资本、算力、科学问题、安全议题、国家级平台、AGI 研究院或机器人系统。

这里的领域级杠杆指：他的工作改变了其他人做研究、训练模型、构建系统、进入行业、组织团队、开发产品、评估风险、使用工具或讨论 AI 未来的方式。

## 为什么不能先设大维度

当前资料验证了用户最初的担忧：如果一开始就设定几个大维度，很多真正关键的机制会被压扁。

| 粗维度 | 会误导的地方 |
|---|---|
| 学术型 | 周志华、朱松纯、张正友都可被称为学术人物，但一个是机器学习共同体，一个是 AGI 研究院，一个是视觉方法到机器人平台。 |
| 创业型 | Wang Xiaochuan、Yan Junjie、Dario Amodei、Ilya Sutskever 的组织机制不同，不能混成创业能力。 |
| 治理型 | Russell/Bostrom/Christiano 是共同语言，Dario Amodei 是安全导向公司，Ilya Sutskever 是单目标安全实验室。 |
| 平台型 | Jeff Dean、Wang Haifeng、Zhou Jingren、Huang Tiejun、Zhang Yaqin 的平台机制不同，有企业基础设施、开发者生态、云模型家族、国家级平台、大学产业研究院等差异。 |
| 中国 AI 人才 | 当前中国样本内部差异极大，不能写成统一画像。 |

更稳妥的方法是：先找原子事实，再抽原子能力，再聚类机制，最后才写画像。

## 总体画像结构

当前 109 条归并能力显示，AI 领军人才通常有四层结构：

| 层级 | 说明 |
|---|---|
| 前史资源 | 他们通常带着某种强前史资源进入 AI：长期研究路线、论文突破、教材、数据集、工具链、搜索产品、跨国研究机构、量化算力、云平台、科学计算方法、视觉方法或治理框架。 |
| 核心杠杆 | 他们在某个机制上形成强影响：结构发明、任务基准、教育解释、工程平台、安全训练、AGI 研究院、创业组织、科学问题、机器人平台等。 |
| 扩散机制 | 他们通过论文、课程、开源、公司、实验室、平台、资本、政策接口、研究院、开发者生态或公共叙事扩散影响。 |
| 领域改变 | 最终体现为别人开始沿着他的路线研究，使用他的工具，采用他的基准，学习他的课程，加入他的组织，使用他的平台，或围绕他的框架讨论问题。 |

## 九类高杠杆路径

36 个机制可以进一步整理为九类高杠杆路径。注意，这九类不是起点，而是当前数据归纳后的表达方式。

### 1. 改变技术路线

这类人物通过长期路线判断、基础方法积累、结构或训练范式发明影响领域方向。

| 机制 | 代表 |
|---|---|
| 长期技术路线判断 | Hinton、Sutton、LeCun |
| 结构与训练范式发明 | Goodfellow、Aidan Gomez、Kaiming He、Saining Xie |
| 前沿模型 scaling 与路线判断 | Dario Amodei、Ilya Sutskever |

关键不是“论文多”，而是他们让后续大量研究沿着某个结构、原则、训练方式或规模化规律展开。

### 2. 改变共同体工作流

这类人物通过数据集、评测、工具链、教材、课程或解释材料改变别人怎么学习和做研究。

| 机制 | 代表 |
|---|---|
| 任务、基准与工具标准化 | Fei-Fei Li、Lin Dahua、Richard Sutton |
| 教育、解释与人才放大 | Andrew Ng、Karpathy、Olah |
| 长期机器学习共同体与教材标准化 | 周志华 |

这类能力看起来像“传播”或“教学”，但实际改变了人才进入领域和研究复用的成本。

### 3. 改变工程和平台基础设施

这类人物把模型、框架、硬件、云、开发者生态和产业应用组织成平台。

| 机制 | 代表 |
|---|---|
| 企业基础设施平台 | Jeff Dean、Wang Haifeng |
| 开发者与企业生态平台 | Wang Haifeng |
| 云与模型家族平台 | Zhou Jingren |

这类领军者的影响不一定来自单个模型，而来自让组织长期拥有训练、部署和迭代 AI 的能力。

### 4. 改变产业和创业路径

这类人物把高校研究、前史资源、技术团队、资本、产品窗口和本土生态连接成公司。

| 机制 | 代表 |
|---|---|
| 高校知识资产到公司技术底座 | Tang Jie、Zhang Peng |
| 前史资源迁移到大模型竞争 | Wang Xiaochuan、Jiang Daxin、Liang Wenfeng |
| 技术团队组装 | Yang Zhilin |
| 创始人集中控制 | Yan Junjie |
| 产品窗口选择 | Yang Zhilin、Jiang Daxin、Zhang Peng、Yan Junjie |

创业路径的重点不是“创业者身份”，而是某种前史资源如何进入大模型窗口，并被组织成团队、产品、融资和部署路径。

### 5. 改变前沿实验室组织形态

这是 v2 之后新增变清楚的路径。

| 机制 | 代表 |
|---|---|
| 安全导向前沿公司 | Dario Amodei |
| 单目标安全实验室 | Ilya Sutskever |
| 前沿公司治理与组织韧性 | Sam Altman、Yan Junjie |

前沿实验室型领军人才不只是“训练最强模型”。他们还会设计组织目标、治理结构、研究优先级和安全/能力耦合方式。

### 6. 改变科学问题求解方式

这类人物把 AI 组织成科学发现工具，而不是只做通用聊天或互联网应用。

| 机制 | 代表 |
|---|---|
| 科学问题与 AI 系统验证 | Demis Hassabis |
| 科学智能组织议程 | Liu Tieyan、Weinan E |
| 科学模型与工具基础设施 | Zhang Linfeng |

AI for Science 不是“AI 应用”的简单子类，它涉及科学问题选择、数学/计算基础、模型方法、跨学科组织和工业 R&D 基础设施。

### 7. 改变 AGI、认知智能和机器人研究组织

这是新增中国长期学术样本后变清楚的路径。

| 机制 | 代表 |
|---|---|
| 跨学科 AGI 研究院与人才组织 | 朱松纯 |
| 经典视觉方法到机器人平台 | 张正友 |
| 大学-产业研究院桥接 | Zhang Yaqin、Lin Dahua |

这说明视觉、认知、机器人和通用智能之间存在一条不同于大模型公司的领军路径。

### 8. 改变风险、治理和公共接口

这类人物不一定通过模型性能领先，而是改变领域如何讨论风险、对齐、部署、监管和公众信任。

| 机制 | 代表 |
|---|---|
| 安全治理共同语言 | Russell、Bostrom、Christiano |
| 公司公共政策与监管接口 | Sam Altman |
| 公共议题与研究叙事影响 | Fei-Fei Li、Hinton、Bostrom |

v2 的重要修正是：安全治理共同语言、安全导向前沿公司和单目标安全实验室必须区分，不能混成一个“安全型人才”。

### 9. 改变组织平台和技术权威结构

这类人物通过实验室、研究院、国家级平台、公司技术权威和跨机构接口维持长期影响。

| 机制 | 代表 |
|---|---|
| 顶级实验室整合 | Demis Hassabis |
| 国家级/区域研究平台 | Liu Tieyan、Huang Tiejun |
| 组织内技术权威 | Jeff Dean |
| 国家工程与工业技术权威 | Wang Haifeng |
| 跨机构技术接口 | Tang Jie、Huang Tiejun、Zhang Yaqin |

这类能力的本质是把个人影响嵌入可持续组织结构，而不是停留在个人成果。

## 证据强度下的结论可靠性

当前 109 条归并能力中，A 级 66 条，B 级 43 条，C 级 0 条。

| 等级 | 含义 | 当前用法 |
|---|---|---|
| A | 有强一手来源、论文或官方资料，能力表述与事实链距离近。 | 可以作为当前报告的主要支撑。 |
| B | 有一手来源或多来源支撑，但能力解释需要更多对照样本。 | 可以作为阶段性结论，但后续需继续补证。 |
| C | 主要依赖媒体/二级资料，或能力解释距离事实太远。 | 当前已清零，不作为画像支撑。 |

这并不意味着当前报告已经最终完成。C 级清零只是说明现有 109 条能力没有明显弱证据项，不代表 61 人名单已经覆盖完整。

## 对“领军人才”的操作性定义

基于当前资料，可以给出一个更可操作的定义：

AI 领军人才，是能在一个或多个关键机制上形成领域级杠杆，并让其他研究者、工程师、公司、学生、政策制定者或产业组织改变行为的人。

这个定义包含三个必要条件：

| 条件 | 说明 |
|---|---|
| 可核验资源 | 他必须有具体可查的前史资源或代表性产物，如论文、模型、工具、组织、课程、公司、平台、著作、研究院。 |
| 机制性转化 | 他必须把资源转化为某种机制，而不是只有个人成就。 |
| 外部行为改变 | 该机制要影响他人如何研究、学习、部署、治理、投资、组织或使用 AI。 |

## 当前结论边界

这份 v2 报告仍有明确边界：

1. 61 人名单中只有 37 个唯一人物进入事实抽取。
2. 109 条归并能力已经超过 100 条，但仍未生成完整合并版总矩阵。
3. 36 个候选机制簇还需要去重，部分可能合并、降级或被新增样本改写。
4. 李开复、黄学东、沈向洋、高文等产业生态、语音识别、跨国研究管理和国家级基础设施样本还没有充分进入事实抽取。
5. 当前画像强调“形成领域影响的机制”，尚未形成正式权重模型。

## 当前最可靠的结论

当前可以较可靠地说：

1. AI 领军人才不能用身份、国别、职位或单一成就定义。
2. 更有效的主轴是“他们改变了领域中什么行为”。
3. 高杠杆机制可以来自技术路线、结构范式、任务基准、教育解释、工程平台、创业组织、安全实验室、科学问题、AGI 研究院、机器人平台或公共治理接口。
4. 低频能力不等于低价值。GAN、Transformer、ImageNet、Superintelligence、SSI、张氏标定法等都可能是低频但高杠杆机制。
5. 中国样本内部机制差异很大，不能写成“中国 AI 领军人才画像”这种统一标签。
6. 安全路径至少有三种：概念共同语言、安全导向前沿公司、单目标安全实验室。

## 最终表达

AI 领军人才的画像，不是“学术、产业、创业、安全、平台”等身份分类，而是一组可证据追溯的机制组合。

他们之所以成为领军人才，是因为他们把某种资源转化成领域级杠杆：有人改变技术路线，有人改变共同体工具，有人改变人才入口，有人改变工程平台，有人改变公司组织，有人改变科学问题，有人改变安全语言，有人改变 AGI/机器人研究组织，有人改变公共治理接口。

判断一个人是否是 AI 领军人才，关键不是看他属于哪一类，而是看他是否让领域里的其他人开始以新的方式行动。
